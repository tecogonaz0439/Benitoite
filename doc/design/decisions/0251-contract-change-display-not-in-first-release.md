# 0251. 契約の変更の表示を初回リリース版に含めず、Agent Skill の手順で示す

- 状態: 採択
- 日付: 2026-09-29
- 関連章: [ロードマップ](../00-overview/00-03-roadmap.md), [Agent Skills 対応](../06-tooling/06-06-agent-skills.md)
- 関連する未決事項: [OPEN-015](../open-issues.md#open-015)

## 背景

ロードマップは、初回リリース版に含めるものとして「契約の変更の表示（[OPEN-015](../open-issues.md#open-015)）」を挙げ、着手の前に決める事項にも「契約の変更の示し方」を挙げていた。一方、[ADR 0231](0231-skill-shows-main-effects-before-running.md) は、同梱の Agent Skill がエージェントに `main` の `uses` を利用者へ示させ、増えたら示し直させるとし、処理系に表示の機能を加えないとした。OPEN-015 は、サーバモードの設計とあわせて決めることになっている（[ADR 0177](0177-server-mode-after-first-release.md)）。ロードマップとこれらの決定が食い違っていた。この食い違いは、初回リリース版の実装プランに着手する前に見つかった。

## 決定

1. 処理系が契約（型とエフェクト）の変更を表示する機能は、初回リリース版に含めない。
2. 初回リリース版で契約の変化を利用者に示すのは、ADR 0231 と [ADR 0249](0249-skill-test-procedure-without-check.md) の Agent Skill の手順（`main` とテストの関数のエフェクトを示し、増えたら示し直す）である。
3. OPEN-015 は、これまでどおりサーバモードの設計とあわせて決める。

## 検討した代替案

- **`check` に `main` のエフェクトを一覧で出す選択肢を加える**: 処理系が読むので、エージェントの読み違いがなくなる。しかし、ADR 0231 を改め、出力の形を設計する必要がある。検査を通ったスクリプトは `main` の `uses` にない組み込みの操作を行わないので、シグネチャを読めば足りる。

## 帰結

- ロードマップの初回リリース版に含めるものから「契約の変更の表示」を外し、着手の前に決める事項の表から「契約の変更の示し方」を外す。
