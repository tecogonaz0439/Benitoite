# 0185. 既定の方針を、スタンドアロンモード・その場で渡すスクリプト・登録したスクリプトで分ける

- 状態: 採択（`server exec` の `Process.Environment` の扱いを [0214](0214-default-policies-allow-process-environment-with-no-names.md) で改めた。スタンドアロンモードの既定を方針のファイルで書く形を [0216](0216-policy-deny-rules-and-standalone-defaults.md) で、既定の方針が指す場所と、`server exec` の既定で作業用のディレクトリの読み取りと一時ディレクトリの読み書きを許すことを [0220](0220-places-referenced-by-default-policies.md) で定めた）
- 日付: 2026-09-29
- 関連章: [セキュリティモデル](../07-quality/07-01-security-model.md)
- 関連する未決事項: [OPEN-015](../open-issues.md#open-015), [OPEN-037](../open-issues.md#open-037), [OPEN-055](../open-issues.md#open-055)

## 背景

利用者が方針を設定していないときに、どれだけ許可するかを決める必要があった。サーバモードの後の処理系が実行するスクリプトは、次の三つに分かれる。

- スタンドアロンモードで実行するスクリプト。個人の利用と、サーバモードに登録するスクリプトのデバッグに使う。
- `server exec` で、その場で渡すスクリプト（[ADR 0181](0181-server-subcommands.md)）。主にコーディングエージェントが書いたもので、利用者はまだ確認していない。
- 登録したスクリプト。利用者が登録のときに確認している。

設計者は、スタンドアロンモードを比較的緩やかに、サーバモード（特にエージェントが渡すスクリプト）を比較的厳しくすることを提案した（[OPEN-055](../open-issues.md#open-055)）。

## 決定

既定の方針を次のとおりとする。

| 実行の種類 | 許可するエフェクト | OS のサンドボックス |
|---|---|---|
| スタンドアロンモード | すべて | 書き込みは、作業ディレクトリと一時ディレクトリの下だけ。秘密を置く場所（`~/.ssh` など）は読めない。ネットワークは使える |
| `server exec` | `Process.Run`、シェルによる実行、`Http.Listen`、`Http.Connect`、`Process.Environment` は許可しない | 読み取りは、基準のディレクトリの下だけ。書き込みは、実行ごとの作業用のディレクトリの下だけ。実行時間に上限を設ける |
| 登録したスクリプト | 登録のときに表示し、利用者が承認したエフェクト。再登録でエフェクトが増えたら、改めて承認を求める | 承認した方針から導く（[ADR 0183](0183-single-policy-for-all-permission-layers.md)） |

秘密を置く場所の一覧、一時ディレクトリと作業用のディレクトリの場所、実行時間の上限の値は、サーバモードの章で定める。

## 検討した代替案

- **スタンドアロンモードには、サーバで設定しない限りサンドボックスを掛けない**: 初回リリース版と同じ振る舞いになり、互換性の変化がない。しかし、サーバモードの後も、何も設定しない利用者の秘密はスクリプトから読める。スタンドアロンモードを使うエージェントのサンドボックスがない場合（[ADR 0179](0179-threat-model-and-server-mode-premise.md)）に、最低限の隔離がなくなる。

## 帰結

- サーバモードを加えた版では、スタンドアロンモードのスクリプトは、作業ディレクトリの外に書けなくなる。初回リリース版との違いは、互換性を壊す変更として扱い、リリースノートに記す（メジャーバージョンが 0 の間は許される。[ADR 0090](0090-version-numbers-and-codenames.md)）。
- 登録のときの承認は、[OPEN-015](../open-issues.md#open-015) の「利用者が権限を読んで実行を承認する手順」に当たる。承認の記録と、エフェクトが増えたときの示し方は、OPEN-015 とサーバモードの章で定める。
- OS のサンドボックスが使えない環境で、既定の方針をどう扱うか（実行を拒否するか、処理系の中の判定だけで実行するか）は、[OPEN-037](../open-issues.md#open-037) で決める。
