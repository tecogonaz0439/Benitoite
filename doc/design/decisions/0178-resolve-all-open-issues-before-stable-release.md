# 0178. すべての未決事項を決着させる時期を、正式リリース版の提供の前とする

- 状態: 採択
- 日付: 2026-09-29
- 関連章: [ロードマップ](../00-overview/00-03-roadmap.md)
- 関連する未決事項: [OPEN-040](../open-issues.md#open-040), [OPEN-055](../open-issues.md#open-055)

## 背景

ロードマップは、初回リリース版を利用者に提供する前にすべての未決事項を決着させ、将来拡張で扱う事項は初回リリース版では扱わないことを ADR に記録して決着させるとしていた。設計書の最終版も、この時点で発行するとしていた。

しかし、実行時の権限制御、OS のサンドボックス、MCP サーバを、初回リリース版の後にサーバモードとあわせて加えることにした（[ADR 0177](0177-server-mode-after-first-release.md)）。これらの方式（[OPEN-037](../open-issues.md#open-037)、[OPEN-052](../open-issues.md#open-052)、[OPEN-055](../open-issues.md#open-055)）は、サーバモードを設計する時点まで決められない。初回リリース版の後に加える機能はほかにもあり、それらの未決事項を初回リリース版の前にすべて決着させることは、設計者の判断では現実的でない。

## 決定

1. すべての未決事項を決着させる時期を、正式リリース版（`1.0.0`）を利用者に提供する前とする。正式リリース版で扱わない事項は、扱わないことを ADR に記録して決着させる。
2. 設計書の最終版は、この時点（正式リリース版の提供の前）で発行する。
3. 初回リリース版を利用者に提供する前には、初回リリース版の範囲にかかわる未決事項を決着させる。

## 検討した代替案

- **初回リリース版のまま、後の版で扱う事項を「初回リリース版では扱わない」と ADR に記録して決着させる**: 規則は保てる。しかし、実際には未決の事項を「決着」と記すことになり、未決事項の一覧が、決めるべきことの一覧として使えなくなる。

## 帰結

- 初回リリース版の後に加える機能の未決事項は、初回リリース版の提供の後も未決として一覧に残る。
- 設計メモへのリンクを外す時期（設計書の最終版の発行）は、正式リリース版の提供の前になる。
- 全ての未決事項の決着は、正式リリース版とする条件（[OPEN-040](../open-issues.md#open-040)）の一つになる。
