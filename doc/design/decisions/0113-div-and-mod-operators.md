# 0113. 整数の除算を `div`、剰余を `mod` と書き、`/` を `Float` に限る

- 状態: 採択
- 日付: 2026-09-28
- 関連章: [字句構造](../01-spec/01-01-lexical.md), [構文](../01-spec/01-02-syntax.md), [基本型の意味論](../01-spec/01-04-types-basic.md), [型システム](../01-spec/01-06-type-system.md), [標準ライブラリ](../03-interop/03-06-stdlib.md)
- 関連する未決事項: [OPEN-012](../open-issues.md#open-012)

## 背景

[ADR 0112](0112-pascal-style-operators.md) で、比較と論理の演算子を Pascal 系の形（`=`・`<>`・`and`・`or`・`not`）にした。一方、整数の除算と剰余は `/`・`%` のままで、C 系の形が残っていた。

Pascal 系の言語の整数の除算と剰余は、次のとおりである。いずれも言語の仕様書で確かめた。

| 言語 | 実数の除算 | 整数の除算 | 剰余 |
|---|---|---|---|
| ISO 7185 Pascal | `/` | `div` | `mod` |
| Free Pascal | `/` | `div` | `mod` |
| Oberon-07 | `/` | `DIV` | `MOD` |
| Ada 2022 | `/` | `/` | `rem`（結果の符号は被除数と同じ）、`mod`（結果の符号は除数と同じ） |

整数の除算の丸め方と剰余の符号は、[ADR 0006](0006-basic-types-semantics.md) で決めた（除算は 0 の方向に切り捨て、剰余の符号は被除数と同じ）。負の無限大の方向に丸める剰余は、関数 `Integer.modulo` として提供している（[ADR 0101](0101-unabbreviated-names.md)）。

## 決定

1. 整数の除算を `div`、剰余を `mod` と書く。`div` と `mod` はキーワードとする。
2. `div` と `mod` の意味は、ADR 0006 の `/` と `%` の意味から変えない。`div` は 0 の方向に切り捨て、`mod` の結果の符号は被除数と同じか 0 である。オペランドは `Integer` に限る。
3. 優先順位と結合性は、`*` と同じ（左結合）とする。
4. `/` のオペランドを `Float` に限る。`Integer` に `/` を使うと型検査の誤りとし、診断は `div` を修正案として示す。実数の商が欲しいときは `Integer.toFloat` で変換してから `/` を使うことも示す。
5. `%` を字句から外す。`%` を書いたときは、`mod` を修正案として示す。
6. 負の無限大の方向に丸める剰余の関数 `Integer.modulo` を `Integer.floorModulo` と改める。`Integer.floorDivide` は変えない。

## 検討した代替案

- **`/` と `%` のまま C 系の形にする**: ADR 0112 の比較と論理の演算子と、書き方の系統が揃わない。
- **`mod` を負の無限大の方向に丸める剰余（Ada の `mod`）にする**: Ada の `mod` と名前と意味が一致する。しかし、ADR 0006 の決定を変えることになる。また、Pascal 系の言語どうしでも `mod` の意味は揃っているとは確かめておらず、Ada に合わせる根拠が弱い。
- **剰余を Ada と同じく `rem` と書く**: 意味（結果の符号は被除数と同じ）は Ada の `rem` と一致する。しかし、Pascal・Free Pascal・Oberon-07 のどれも `rem` を使わない。
- **`/` を `Integer` にも使う（Ada と同じ）**: `div` と `/` の二通りで整数を割れることになり、同じ役割の構文を増やす（設計原則 5）。`/` を `Float` に限れば、`7 / 2` を実数の商のつもりで書いた誤りを型検査で報告できる。
- **`Integer.modulo` の名前を変えない**: 演算子の `mod` と関数の `modulo` が同じ語に由来するのに、結果の符号の規則が違う。名前から違いが読み取れるように、関数の名前に丸めの方向（`floor`）を入れ、`Integer.floorDivide` と対にする。

## 帰結

- `div`・`mod` を識別子に使っていたスクリプトは誤りになる。
- `7 / 2` は型検査の誤りになり、`7 div 2` か `Integer.toFloat(7) / 2.0` と書く。
- `mod` の意味は、Ada の `mod` と異なり、Ada の `rem`、C・Go・Rust の `%` と同じである。LLM が `mod` を負の数に使ったときにどちらの意味を想定して書くかを、[OPEN-012](../open-issues.md#open-012) の測定の対象とする。
