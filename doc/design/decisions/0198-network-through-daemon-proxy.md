# 0198. サーバモードの子プロセスの通信は、デーモンが持つプロキシだけを通し、プロキシが接続先のホスト名を判定する

- 状態: 採択
- 日付: 2026-09-29
- 関連章: [OS のサンドボックス](../02-impl/02-12-os-sandbox.md), [サーバモード](../06-tooling/06-07-server.md)
- 関連する未決事項: [OPEN-052](../open-issues.md#open-052)

## 背景

方針は、`Http.Connect` の対象に接続先のホスト名を書く（[ADR 0184](0184-permissions-granted-per-builtin-effect.md)）。スクリプト自身の通信は、子プロセスの中の処理系の判定器がホスト名で判定できる。しかし、スクリプトが `Process.Run` で起動した外部コマンド（`curl` など）の通信は、処理系の判定器の外にある。

Seatbelt・Landlock・seccomp のどれも、ホスト名では通信を制限できない。Seatbelt は宛先を「すべて」か「localhost」とポートでしか書けず、Landlock はポートでしか制限できず、seccomp は `connect` の宛先を調べられない。Codex と Claude Code は、子プロセスの直接の通信を塞ぎ、サンドボックスの外に置いた HTTP と SOCKS5 のプロキシで接続先のホスト名を判定する（[OS のサンドボックス](../02-impl/02-12-os-sandbox.md)に出典を記す）。

## 決定

1. サーバモードの最初の版から、デーモンは HTTP のプロキシを持つ。プロキシは、HTTP の要求の宛先と、HTTPS の CONNECT の宛先のホスト名を、実行ごとの方針の `Http.Connect` の許可と照らし、許可していない宛先への接続を拒否する。
2. 子プロセスの直接の外向きの通信は、OS のサンドボックスで塞ぎ、プロキシへの接続だけを通す。
   - Seatbelt: 外向きの通信を、localhost のプロキシのポートにだけ許す。
   - Landlock: TCP の接続を、プロキシのポートにだけ許す。
   - bubblewrap: ネットワークの名前空間を切り離し、名前空間の中からプロキシへつなぐ経路を設ける。
3. 子プロセスの中の処理系は、`Http.Connect` の操作をプロキシを通して行う。スクリプトが起動した外部コマンドには、`HTTP_PROXY`・`HTTPS_PROXY` などの環境変数でプロキシを示す。環境変数に従わないコマンドは、直接の通信を塞がれているので、通信できない。
4. 待ち受け（`Http.Listen`）は、プロキシを通さない。方針が許した待ち受けのアドレスとポートにだけ、OS のサンドボックスで待ち受けを許す。
5. 処理系の中の判定器も、`Http.Connect` の許可をホスト名で判定する。プロキシは、外部コマンドの通信と、判定器の不具合に対する多層の防御である。
6. TLS の中身は検査しない（MITM をしない）。このため、CONNECT で名乗るホスト名と実際の通信先が違う手口（domain fronting）は防げない。名前解決した IP アドレスが localhost や私的なアドレスであるときの扱いは、[OPEN-052](../open-issues.md#open-052) の「判定する時点」とあわせて決める。

## 検討した代替案

- **最初の版は、処理系の判定器と OS のポート単位の制限だけで行う**: 作業が少ない。しかし、外部コマンドの通信は、許したポートならどこへでも届く。
- **OS では、ネットワークを全部許すか全部塞ぐかだけにする**: 最も簡単である。しかし、一部の接続先を許すと、外部コマンドはどこへでも通信できる。

## 帰結

- 外部コマンドの通信も、ホスト名で制限できる。
- プロキシの実装、各仕組みでプロキシのポートだけを通す設定、bubblewrap の名前空間の中からプロキシへつなぐ経路が加わる。
- Landlock の TCP の制限はカーネル 6.7 から効く。それより前のカーネルでは、直接の通信を塞げないので、ネットワークを許す方針のスクリプトは [ADR 0197](0197-when-os-sandbox-is-unavailable.md) の扱いになる。UDP（DNS を含む）は、Landlock ではカーネル 7.2 より前は制限できない。
- スタンドアロンモードの子プロセスの扱い（スタンドアロンモードも同じプロキシを使うか）は、[サーバモード](../06-tooling/06-07-server.md)で定める。
