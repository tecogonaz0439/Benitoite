# 0220. 既定の方針が指す場所（実行ごとの作業用のディレクトリ、一時ディレクトリ、秘密を置く場所の一覧）を定める

- 状態: 採択（決定 1 と 2 の場所を [0250](0250-run-directories-outside-daemon-data.md) で改めた）
- 日付: 2026-09-29
- 関連章: [サーバモード](../06-tooling/06-07-server.md), [セキュリティモデル](../07-quality/07-01-security-model.md)
- 関連する未決事項: [OPEN-055](../open-issues.md#open-055), [OPEN-057](../open-issues.md#open-057)

## 背景

既定の方針（[ADR 0185](0185-default-policies-per-run-kind.md)）は、秘密を置く場所、一時ディレクトリ、実行ごとの作業用のディレクトリを指すが、それぞれの場所は「サーバモードの章で定める」としたまま定めていなかった。サーバモードの章の方針のファイルの例は、書き込みの範囲を `./.benitoite-work`（基準のディレクトリの下）としており、ADR 0185 の「実行ごとの作業用のディレクトリ」と合っていなかった。

## 決定

1. 実行ごとの作業用のディレクトリは、デーモンのデータのディレクトリの下の `runs/<ジョブの ID>/work` とする。ジョブの記録を消すとき（[ADR 0199](0199-server-job-handling.md)）に、あわせて消す。
2. 一時ディレクトリは、実行ごとに `runs/<ジョブの ID>/tmp` とし、環境変数 `TMPDIR` で子プロセスに示す。
3. 既定の秘密を置く場所の一覧は、次のとおりとする。利用者は、認証を要する操作で一覧に加えられる。
   - `~/.ssh`、`~/.gnupg`、`~/.aws`、`~/.config/gcloud`、`~/.azure`、`~/.kube`、`~/.docker`、`~/.netrc`
   - macOS では `~/Library/Keychains`
   - ウェブブラウザのプロファイル（OS ごとの場所は【要検証】。[OPEN-057](../open-issues.md#open-057)）
   - Benitoite 自身の設定とデータのディレクトリ
4. `server exec` の既定の方針は、作業用のディレクトリ（`{work}`）への書き込みに加えて、`{work}` の読み取りと、一時ディレクトリ（`{tmp}`）の読み取りと書き込みを許す。これは、読み取りを基準のディレクトリの下だけ、書き込みを作業用のディレクトリの下だけとした ADR 0185 の既定を、少し広げる。
5. サーバモードの章の方針のファイルの例を、ADR 0185 の既定の方針（[ADR 0214](0214-default-policies-allow-process-environment-with-no-names.md) で改めた `Process.Environment` を含む）に合わせる。

## 検討した代替案

- **方針のファイルの例だけを直し、場所はすべて [OPEN-055](../open-issues.md#open-055) に登録する**: 決める事項が減る。しかし、既定の方針が指す場所が決まらないままでは、既定の方針から OS のサンドボックスの設定を導けない（[ADR 0183](0183-single-policy-for-all-permission-layers.md)）。

## 帰結

- ADR 0185 の `server exec` の既定のうち、読み取りと書き込みの範囲を、決定 4 で改めた。
- 子プロセスに渡す環境変数に `TMPDIR` が加わる。[ADR 0199](0199-server-job-handling.md) の決定 6 の「ほかにはプロキシの環境変数だけを渡す」を、この ADR で改める。
- 作業用のディレクトリは基準のディレクトリの外にあるので、書き込んだ結果を利用者に渡す手段（ジョブの出力として取り出すなど）が要る。この手段と、スクリプトが作業用のディレクトリのパスを知る方法は、[OPEN-055](../open-issues.md#open-055) で決める。
