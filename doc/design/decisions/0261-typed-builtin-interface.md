# 0261. 組み込みの関数は型付きの形で書き、権限ごとの文脈と共通の完了の処理を通す

- 状態: 採択（決定 8 の【未決】を [0286](0286-unofficial-modules-imported-under-unofficial.md) で決めた）
- 日付: 2026-09-30
- 関連章: [仮想機械](../02-impl/02-08-vm.md), [ランタイム](../02-impl/02-09-runtime.md), [標準ライブラリ](../03-interop/03-06-stdlib.md)
- 関連する未決事項: [OPEN-066](../open-issues.md#open-066)

## 背景

最小実行版の組み込みの関数は `fn(&mut Heap, &[Value]) -> Result<Value, Stop>` の形である。初回リリース版では、応答に「待つ」「タスクの起動」「終了」が加わる（[仮想機械](../02-impl/02-08-vm.md)の「組み込みの関数の呼び出し」）。標準ライブラリ（U3）では、数百の関数を LLM が書く。この形は U3 を書き始める前に固める必要がある。

内部の共通の形を `fn(&mut Ctx, Args) -> Result<Reply, Stop>` とし、それを実装者に直接書かせると、引数の型・権限（純粋な関数が「待つ」を返すなど）・大きさの確かめの誤りが、実行するまで分からない（[相談の第 1 回](../../implement/studies/u2-runtime/consult/01-memory-and-values.md)の問い 6）。

## 決定

1. 組み込みの関数の内部の共通の形は、文脈（`Ctx`）と引数を受け取り、応答（完了・待つ・タスクの起動・終了）か停止を返す関数とする。この形は処理系の内部にとどめる。
2. 組み込みの関数の実装者は、名前と型の付いた引数を受け取る関数だけを書く。引数の読み出しと登録の表は、関数の宣言から作る。
3. 文脈は、関数の権限ごとに分ける。純粋な関数には、時計・乱数・リソースに触れず、`Wait`・`SpawnTasks`・`Exit` を返せない文脈を渡す。権限の誤りはコンパイルの誤りになる。
4. 値を作る関数は、確保の前に大きさを確かめる（[ADR 0049](0049-size-limit-for-built-values.md)）。実装者には、確かめた長さを受け取る確保の関数か、上限付きの構築器を使わせる。UTF-8 の確かめは、文字列の値を作る API に集める。
5. 作業用のスレッドに渡す仕事と結果は `Send + 'static` の型にする。完了を言語の値に変える処理は、環境を捕えない `fn` ポインタにする。待つ間に要る言語の値は、閉包に捕えず、枠のレジスタに残す。
6. 完了の保存、起動する関数の登録、取り消しとの競合、リソースの返却は、共通の部分が行い、個々の組み込みの関数に任せない（[ADR 0266](0266-task-and-resource-state-machines.md)）。
7. 第 1 段（[ADR 0268](0268-staged-runtime-rebuild.md)）で、純粋な関数・文字列を作る関数・待つ関数を一つずつこの形で書き、誤った引数の型・結果の型・権限・捕捉がコンパイルで止まることを確かめる。
8. 【未決】この形で書いた関数を、まず非公式のライブラリとして扱い、実装を吟味したものから標準ライブラリに加える方向を、設計者が示した（2026-09-30）。標準ライブラリの範囲、非公式のライブラリの位置付けと利用者からの見え方は、U3 の実装プランを作るときに決める（[OPEN-066](../open-issues.md#open-066)）。

## 検討した代替案

- **共通の形で書き始め、定型が固まってから包みを入れる**: 仕組みが小さい。しかし、権限と引数の誤りが実行時まで分からず、数百の関数を書いた後で包みに移すと、書き直しが大きくなる。
- **組み込みの関数を小さく保ち、多くを標準ライブラリのソースで書く**: Rust で書く範囲が減る。しかし、遅くなり、U3 の設計の範囲を広く変える。
- **宣言的な包みを `macro_rules!` で作る**: 定型が減る。採る形の一つだが、マクロが読みにくくなると設計者が読んで学ぶ妨げになる。包みの作り方（マクロか、手書きの薄い関数か）は実装プランで決める。

## 帰結

- 標準ライブラリの関数は、すべてこの形で書く。U3 の実装プランは、決定 8 の未決の点を先に決める。
- 決定 8 の結論によっては、[標準ライブラリ](../03-interop/03-06-stdlib.md)と [ADR 0137](0137-first-release-library-scope.md) の初回リリース版のライブラリの範囲を改める。
- 包みの形と権限ごとの文脈の型は、実装プランの `10-interfaces/` で凍結する。
