# 0054. 循環する import を誤りとする

- 状態: 採択
- 日付: 2026-09-26
- 関連章: [名前・スコープ・モジュール](../01-spec/01-03-names-modules.md)
- 関連する未決事項: なし

## 背景

モジュール A が B を取り込み、B が A を取り込むと、import は循環する。循環を許すと、循環するモジュールをまとめて名前解決と型検査にかける必要がある。

## 決定

import の循環を誤りとする。誤りの診断は、循環を作る import の並び（`a.bnt -> b.bnt -> a.bnt`）を示す。

## 検討した代替案

- **循環を許す**: 互いに呼び合う関数を別のファイルに置ける。しかし、循環するモジュールを一つの単位として検査する仕組みが要り、型の誤りがどのモジュールの変更から来たのかも示しにくくなる。

## 帰結

- 処理系は、モジュールを依存の順に並べ、一つずつ名前解決と型検査にかけられる。
- 互いに呼び合う関数は同じモジュールに置くか、共通の部分を別のモジュールに分けて循環を解く。
