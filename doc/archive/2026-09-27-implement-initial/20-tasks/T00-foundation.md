## 目的

Cargo のワークスペース、Rust の版の固定、lint の水準、警告を誤りにする設定、ライセンスの検査の設定、完了条件の共通の検査をまとめて行うスクリプトを置く。以後のすべての作業は、この作業が置いた設定とスクリプトで完了条件を確かめる。あわせて、AGENTS.md に実装の規約の節を加え、どの LLM とハーネスも同じ規約を読むようにする（07-03「実装の規約と静的な検査」の最後の段落）。

## 作るもの

パスはリポジトリの根からの相対である（この作業だけ、処理系のクレートの外のファイルを作る）。

| ファイル | 内容 |
|---|---|
| `Cargo.toml` | ワークスペースの定義。内容は 00-02「Rust の版と設定」のとおり |
| `crates/benitoite/Cargo.toml` | 処理系のクレートの定義。内容は 00-02 のとおり |
| `crates/benitoite/src/lib.rs` | `//! Benitoite の処理系（最小実行版）。` の 1 行だけ。T01 が置き換える |
| `rust-toolchain.toml` | `[toolchain]` に `channel = "1.98.1"` と `components = ["clippy", "rustfmt"]` |
| `.cargo/config.toml` | `[build]` の `warnings = "deny"` |
| `deny.toml` | cargo-deny の設定。許可するライセンスは `MIT` と `Apache-2.0` だけ |
| `scripts/check.sh` | 完了条件の共通の検査を順に行うスクリプト |
| `.gitignore` | `/target` を加える（既存の行は変えない） |
| `AGENTS.md` | 「実装の規約」の節を加え、「プロジェクトの概要」の一文を改める（後述） |

## 手順の要点

- `crates/benitoite/src/lib.rs` を 1 行だけ置くのは、ソースのないクレートでは `cargo` の検査が走らないからである。この 1 行は T01 が 10-interfaces から取り出した `lib.rs` で置き換える。
- `scripts/check.sh` は bash で書き、先頭で `set -euo pipefail` を指定する。リポジトリの根に移ってから、00-02「完了条件の共通の検査」の表の 5 つのコマンドを表の順に実行する。各検査の前に `== <検査の名前>` の行を出し、失敗したら `FAILED: <検査の名前>` を標準エラー出力に書いて終了状態 1 で終わる（最初の失敗で止まる）。すべて通ったら `all checks passed` を出して終了状態 0 で終わる。実行の権限（`chmod +x`）を付ける。
- `cargo deny` が入っていないときは、`cargo install cargo-deny --locked` で入れるよう示す文を出して終了状態 1 で終わる。黙って飛ばさない。
- `deny.toml` は `[licenses]` の `allow = ["MIT", "Apache-2.0"]` だけを書き、ほかの検査（advisories、bans、sources）の節は書かない。検査するのはライセンスだけである（07-03 の表）。cargo-deny が処理系自身のライセンス `MIT OR Apache-2.0` を読めることを確かめる。
- AGENTS.md の編集:
  - 「プロジェクトの概要」の「現在は設計書と最小実行版の実装プラン（…）があり、処理系のソースコードはまだなく、ビルド・テストの手順もない（実装プランの作業 T00 で加える）。」を、処理系のソースコードが `crates/benitoite/` にあることと、検査の手順が `scripts/check.sh` であることを示す文に改める。
  - 「ディレクトリ構成」の表に、`crates/benitoite/`（処理系のクレート）と `scripts/check.sh`（完了条件の共通の検査）の行を加える（実装プランの行はすでにある）。
  - 新しい節「実装の規約」を「テストの運用」の後に加える。中身は 00-02「文章で守る規約」の小節（型とシグネチャを変えない、失敗を panic で表さない、大域の状態、再帰の深さ、言語の値を作る経路、数値の変換、`#[allow]` を書いてよい箇所、文言、コメントと名前）を写したものとする。写した節の冒頭に、正は実装プランの 00-02 であり、食い違ったら 00-02 に合わせることを一文で書く。
  - ほかの節は変えない。
- Rust の版は 1.98.1 に固定する。`rustup` が版を入れていなければ、`rust-toolchain.toml` を置いた後の最初の `cargo` の実行で自動で入る。

## 受け入れテスト

- `scripts/check.sh` を実行すると、5 つの検査がすべて通り、終了状態 0 で終わる。
- `crates/benitoite/src/lib.rs` に一時的に `pub fn f(v: &[i32]) -> i32 { v[0] }` を加えて `scripts/check.sh` を実行すると、lint の検査で失敗し、`FAILED: lint` を出して終了状態 1 で終わる（確かめたら元に戻す）。
- 一時的に `crates/benitoite/src/lib.rs` の書式を崩すと、書式の検査で失敗して止まる（確かめたら元に戻す）。
- `cargo --version` が 1.98.1 の Cargo を示す。

この作業は処理系の振る舞いを持たないので、Rust のテストは書かない。上の確認は手で行い、完了の報告に結果を書く。

## 完了条件

- scripts/check.sh が通る（00-02「完了条件の共通の検査」）
- 受け入れテストのすべての場合を手で確かめ、完了の報告に結果を書いている
- AGENTS.md の変更が、上の 3 箇所だけである
