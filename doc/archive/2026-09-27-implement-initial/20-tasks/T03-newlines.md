## 目的

字句の切り出し（T02）が作った改行の印 `LineBreak` ごとに、改行字句 NEWLINE（`TokenKind::Newline`）を置くか、空白として捨てるかを決める（02-03「処理の流れ」の工程 2）。出力の字句の列は構文解析器（T11・T12）の入力になり、文の区切りは NEWLINE だけで表される。

## 手順の要点

- 字句の列を先頭から一度だけ辿る。開いている括弧の積み重ね（`(`・`[`・`{` の種類の `Vec`）を持つ。開き括弧で積み、閉じ括弧で、積み重ねの最も上が対応する開き括弧なら降ろす。対応しない閉じ括弧（`(` に対する `]` など）と、空の積み重ねでの閉じ括弧は無視し、積み重ねを変えない。括弧の対応の誤りは構文解析器が報告する（本作業では診断を出さない）。
- 連続する `LineBreak`（コメントだけの行と空の行が作るもの）は、一つの改行としてまとめて判定する（01-01「コメントだけの行と空の行は、判定の上では存在しないものとして扱う」）。まとめた改行の「直前の字句」は、連続の前にある `LineBreak` でない最後の字句、「直後の字句」は連続の後にある最初の字句（`Eof` を含む）である。
- まとめた改行ごとに、01-01 の規則 1〜4 を順に当てる。
  1. 積み重ねの最も上が `(` か `[` なら捨てる。
  2. 直前の字句が規則 2 の一覧（二項演算子 `+ - * / % == != < <= > >= && || |>`、`!`、`=`、`->`、`=>`、`:`、`,`、`.`、開き括弧、キーワード `else`・`fn`・`if`・`let`・`match`・`type`・`uses`）にあれば捨てる。v1 のキーワードは最小実行版の字句にないので、一覧に入れない。
  3. 直後の字句が規則 3 の一覧（`-` を除く二項演算子 `+ * / % == != < <= > >= && || |>`、`.`、`->`、`=>`、`else`）にあれば捨てる。
  4. どれにも当たらなければ、`Newline` の字句を一つ置く。span は、まとめた改行のうち最初の `LineBreak` の span とする（本作業で決める。`{` を次の行に書いた誤り E0205 の位置を、改行の位置として示せるようにするため）。
- ファイルの先頭の改行（直前の字句がないもの）は捨てる。ファイルの終わりの改行（直後の字句が `Eof`）は、規則 1〜4 に従って `Newline` を置いてよい。文法の `LineList` は前後の NL を許すので、どちらでも構文解析器は読める（本作業では、先頭は捨て、終わりは規則どおりとする）。
- `Error` の字句は、規則 2・3 の一覧に当たらない普通の字句として扱う。
- 出力に `LineBreak` を残さない。`Newline` は連続しない。

## 受け入れテスト

いずれも、ソースを T02 の `lex` にかけた結果を `resolve_newlines` に与え、出力の字句の種類の並びを確かめる。

- `let total = price\n  * quantity` は、`*` の前に `Newline` を置かない（規則 3）。
- `let n = lines\n  |> List.filter(fn(l) { l != "" })\n  |> List.length` は、`|>` の前に `Newline` を置かない。
- `if ready {\n  start()\n} else {\n  wait()\n}` は、`}` と `else` の間に `Newline` を置かず、`{` の後の改行を捨て（規則 2）、`start()` と `}` の間には `Newline` を置く。
- `fn double(x: Int) -> Int\n{` は、`Int` と `{` の間に `Newline` を置く（E0205 の元になる形）。
- `f(a,\n  b)` と `[1,\n 2]` は、括弧の中なので `Newline` を置かない（規則 1）。`{` の中の `(` の中の改行も捨てる。
- `a +\n b` は規則 2 で捨てる。`a\n- b` は、`-` が規則 3 の一覧にないので `Newline` を置く。
- `a\n\n// comment\n\nb` は、`a` と `b` の間に `Newline` を一つだけ置く。
- ファイルの先頭の空の行とコメントの行は `Newline` を作らない。
- 対応しない閉じ括弧 `)` を含む入力でも、panic せずに出力を返す。
- 出力に `LineBreak` がなく、`Newline` が連続しない（上のすべての入力で確かめる）。

## 難易度の理由

規則は 01-01 に四つの箇条で定まっており、括弧の積み重ねを持って列を一度辿るだけで判定できる。注意が要るのは、連続する改行をまとめてから判定することと、規則 3 の一覧から `-` を除くことである。
