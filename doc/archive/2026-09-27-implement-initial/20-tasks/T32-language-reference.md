## 手順の要点

### 文書の言語と形

- 文書は英語で書く。読み手が LLM であり、診断の文言も英語である（ADR 0033）ため、文書と診断の用語を揃えられるからである。この決定は本プランで仮に決めたものであり、OPEN-012 の測定を設計するときにユーザーが確かめる。
- 文書の先頭に、対象が最小実行版であること、名前・拡張子・コマンドの名前が仮のもの（OPEN-011）であることを書く。
- 設計書の規則を写すのではなく、スクリプトを書く人が使う形に書き直す。理由や代替案は書かない。長さの目安は 600 行以内とする。

### 載せる内容

節の構成は次のとおりとする。

1. Running a script: `benitoite run` と `benitoite check`、終了状態 0〜3、`--diagnostics=json`
2. Program structure: `fn main`、トップレベルに置けるもの、文は改行で区切ること、`{` を同じ行に書くこと、`;` を使わないこと、コメント
3. Basic types and literals: 6 つの基本型、リテラルの書き方、演算子と優先順位、`Int` の溢れと除算、`Float` の比較、文字列の `+`、暗黙の変換がないこと
4. Functions and lambdas: 型注釈が必須の位置と省略できる位置、カリー化しないこと、プレースホルダ `_`、パイプ `|>` の展開の規則、末尾呼び出しの保証、繰り返しの構文がないこと（再帰と `List` の関数を使う）
5. Data types and pattern matching: `type` の宣言、構成子を型名で修飾すること（`Some`・`None`・`Ok`・`Err` は例外）、パターンの種類、網羅性と選ばれない分岐の検査、`List` をパターンで分解できないこと
6. Effects: `uses IO`、純粋な関数から IO を呼べないこと、`effect E` によるエフェクト変数、ラムダのエフェクトの推論
7. Errors: `Result[T, IoError]` を `match` で扱うこと、`main` が `Result[Unit, String]` を返す形、`unwrap` がないこと（`unwrapOr` と `match`）、実行時エラーは捕捉できないこと
8. Prelude reference: モジュールごとの関数の表（名前、型、一行の説明、実行時エラー）。10-10 の一覧の演算子と `List.dropFirst` を除くすべての関数と、10-11 の prelude のソースの関数を載せる
9. Diagnostics: 診断の形（コード、位置、`help:`）と、よくある誤りと直し方（`String.length` がないこと、`xs.map(f)` の代わりにパイプを使うこと、比較を連ねないことなど）

### コードの例

- 検査を通るべきコードの例は、`` ```bnt `` で始めるコードブロックに書く。各ブロックは `main` を含む完全なプログラムにする。
- 誤りの例や、プログラムの一部だけを示す例は `` ```text `` で書き、テストの対象にしない。
- 例は少なくとも次のものを含める: ファイルを読んで行数を数えるプログラム（01-07「プログラムの入口」の例）、代数的データ型とパターンマッチで集計するプログラム、パイプとプレースホルダを使うプログラム、エフェクト変数を持つ高階関数を定めて使うプログラム。

### テスト

`crates/benitoite/tests/language_reference.rs` は次の二つを確かめる。

1. 文書の `` ```bnt `` のブロックを一つずつ取り出し、`pipeline::check_text` に渡して、診断がないことを確かめる。失敗したら、ブロックの先頭の行番号と診断の文言を示す。
2. 組み込みの関数のうち演算子でなく prelude 専用でないもの（`BuiltinId::ALL` を `builtins::table::spec` で調べる）と、prelude のソースの修飾した関数（`prelude::SOURCES` を構文解析して `FnDecl.module` を持つもの）について、`モジュール名.関数名` の字面が文書に現れることを確かめる。

## 難易度の理由

処理系のコードを変えず、設計書の規則をスクリプトの書き手の視点でまとめ直す作業である。正確さはテスト（例の検査と関数の網羅）で確かめられる。どの規則を載せ、どれを省くかの判断と、LLM が誤りやすい点（改行の規則、修飾、単位を持つ文字列の関数）を落とさないことに注意が要る。
