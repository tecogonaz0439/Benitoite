## 言明が参照する定義の C2 での変更（軽4）

レビューが確かめた内容を、取りまとめの受け入れの記録として残す。

| 定義 | 変更 | 向き |
|---|---|---|
| `EvalPartial` | Integer64 の減算・乗算・負号、六幅の規則、`matchWidth` を具体規則として追加 | 未知の規則を言語仕様どおりの具体規則へ置き換える |
| `Unmodeled`・`matchOtherNormal`・`matchOtherFailed` | 具体規則を持つ形を除外 | 未知の範囲を接続した形に限って狭める。重なりも欠けもない |
| `ConcreteValue` | 六幅の構成子を追加し、`other` の除外を `IntKind.ofType type = none` にした | 具体値の範囲が七種の整数へ広がる |
| `targetOperationAt`・`concreteRule` | 事象を作る形を拡大 | `Unmodeled` から外した形とちょうど一致する |
| `AbstractSlot`・`topSlot`・`SlotModels` | `integerKind` の場合を追加 | `SlotModels` の既存の場合は不変で、新しい場合を足しただけ。`Models` は強まらない |
