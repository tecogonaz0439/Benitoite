# RV-A21 への対応

2026-10-26、取りまとめ。判定は条件付き受け入れ（中1・軽3）。レビューは API キーの別プロセス（Opus 5.5、effort high）で行い、費用は 3.72 ドルだった。

| 所見 | 扱い | 時期・場所 |
|---|---|---|
| 中1 組み込みの操作の頭で、標準表の照会が Lean より一回少ない | 修正案 1。Rust の `standard_direct_call` で組み込みの操作（`Failure.raise` を除く）の頭も照会する。組み込みの操作の call を含む形を予算の固定表に加え、Lean から作り直す。Lean の例の操作の頭を `.primName` に直し、操作の除外が標準表の中身に依ることを 01-12・07-04 に書く。Lean の定義は変えない | A21d |
| 軽1 D16 の追記が L25T・A19b の後の状態と合わない | decisions.md の D16 の追記（L25R・L25S を受けて）に訂正を加えた | 対応済み |
| 軽2 シフトの呼び出しの計上を Lean の実行値と照合した検査がない | シフトの call を含む形を予算の固定表に加える | A21d |
| 軽3 `copy_within` の前提がコメントにない | 前提をコメントに書くか、panic しない書き方にする | A21d |
