## 変更の範囲

七種の型域・リテラル、種類付きの局所位置、その bind・shadow・参照・捕捉の忘却・合流を接続した。Integer と Integer64、UnsignedInteger と UnsignedInteger64 はそれぞれ同じ解決済みの型として認定する。Byte を整数七種へ含めない。

`domain.rs` は種類ごとの有限な上下限・Top・正規化を提供する。Interval は端点だけを保持し、同じ種類の成分どうしで交差・合流する。`input.rs` は型検査済みの共有リテラル表から種類と i128 の値を読む。値域外の幅付きの葉は Bottom にせず Top と未対応にする。Rust の共有表は固定幅整数を保持するため、値域外の表層 Nat を直接作る入口はない。型検査済みの元位置と負の葉の分類を保った。

六幅の正常値と return は、Integer64 とは別の六成分の固定長配列に保持する。Top と全 Bottom は列挙型で表し、精密な成分が必要なときだけ配列を確保する。環境の位置には整数の種類を保存し、忘却はその種類の Top にする。合流は基準位置の種類で左右を一回ずつ読み、後続の位置へ進んでから内側の順に項目を保存する。新しい計上単位は追加していない。

`discovery.rs` の引数・通常束縛の初期位置、`flow.rs` のリテラル・束縛・局所参照・正常値と return の合流も、これらの部品へ接続した。02-05 の値域・環境・リテラルと合流の説明を更新した。現在の比較・算術・match が Integer64 に限られる境界は維持した。
