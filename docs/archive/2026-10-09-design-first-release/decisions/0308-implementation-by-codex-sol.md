# 0308. 初回リリース版の実装は、難易度によらず Codex（GPT-6.1-Sol、推論の度合い high）が行う

- 状態: 採択
- 日付: 2026-10-02
- 関連章: [処理系のテスト戦略](../07-quality/07-03-compiler-testing.md)
- 関連する未決事項: [OPEN-059](../open-issues.md#open-059)
- 改める ADR: [ADR 0285](0285-implementer-assignment-for-first-release.md)

## 背景

[ADR 0285](0285-implementer-assignment-for-first-release.md) は、初回リリース版の実装を Codex（GPT-6-Luna、推論の度合い max）を基本とし、難易度 5 の 12 件を Claude Opus 5.5 のサブエージェントが実装して GPT-6-Astra がレビューすると決めた。実装を始めるにあたり、設計者は、できる限りの作業を Codex と GPT-6.1-Sol（推論の度合い high）で実装し、Claude Code はオーケストレータとレビューに徹するよう指示した。GPT-6.1-Sol は、形式化の段階 A のレビューで GPT-6-Astra の 5 分の 1 のレートの消費で同等以上の指摘をした実績がある（`formal/reviews/2026-09-30-stage-a-definitions/`）。

## 決定

1. 初回リリース版の実装プランの作業は、難易度によらず Codex（モデル GPT-6.1-Sol、推論の度合い high）が実装する。ADR 0285 の決定 1・2 を置き換える。
2. Claude Code はオーケストレータとして作業を配り、確かめ、取り込み、設計書と実装プランの修正に当たる。作業の実装は行わない（ADR 0285 の決定 5 を引き継ぐ）。
3. すべての作業を、オーケストレータが実装プランの 00-04 の観点で確かめる。
4. Codex は実装に専念させ、レビューに使わない。難易度 5 の作業（C14、F08、F09、F15、R01、R02、R04、R09、R20、R21、R25、R26、L30）と `runtime::heap` を変える作業も、オーケストレータが確かめる。`runtime::heap` の作業では、オーケストレータが `// SAFETY:` のコメントの引く不変条件が実際に成り立つかを読む。ADR 0285 の決定 3（GPT-6-Astra によるレビュー）を置き換える。GPT-6-Astra は、設計者が指示したときだけ使う。（当初は、これらの作業を実装とは別の Codex の会話にもレビューさせると決め、R01 に適用した。同日、設計者の指示で、Codex を実装に専念させる形に改めた。）
5. D31・D32 は、ADR 0292 のとおりオーケストレータが設計者と行う。

## 理由

実装とレビューを別の系統のモデルに分ける ADR 0285 の考えは、Codex の実装をオーケストレータ（Claude）が確かめる形で保たれる。Codex のレートを実装に充てるため、レビューはオーケストレータに集める。

## 帰結

- 実装プランの作業一覧の「担当」の欄と、作業の進め方（00-03）の「担当と起動の方法」を改める。
- エージェントの定義 `impl-medium`・`impl-low` は使わない。
