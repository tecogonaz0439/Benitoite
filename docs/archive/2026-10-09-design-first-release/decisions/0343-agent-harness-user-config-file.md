# 0343. エージェントハーネスの提供者とモデルを、利用者単位の TOML の設定ファイルに書く

- 状態: 採択
- 日付: 2026-10-08
- 関連章: [エージェントハーネス](../06-tooling/06-08-agent-harness.md), [CLI](../06-tooling/06-01-cli.md)
- 関連 ADR: [0340](0340-llm-providers-for-own-agent-harness.md), [0187](0187-standalone-reads-user-policy-file.md), [0127](0127-directory-run-and-root.md)
- 関連する未決事項: [OPEN-048](../open-issues.md#open-048), [OPEN-101](../open-issues.md#open-101), [OPEN-102](../open-issues.md#open-102)

## 背景

エージェントハーネスは、複数の LLM の提供者を採る（[ADR 0340](0340-llm-providers-for-own-agent-harness.md)）。利用者は、どの提供者のどのモデルを使うかを指定する必要がある。設計者は、2026-10-04 に、指定のしかたを決めた（[自前のエージェントハーネスの検討メモ](../sources/post-first-release/post-first-release-agent-harness.md)の「設計者の決定」と「設定ファイル」）。

主なハーネス（Claude Code、Codex CLI、OpenCode など）は、使うモデルを設定ファイルに書く。処理系は、プロジェクトの設定ファイルを読まず、作業ディレクトリや親のディレクトリを辿って設定ファイルを探さない（[ADR 0127](0127-directory-run-and-root.md)）。サーバが書く利用者単位の方針のファイルは、利用者の方針であってプロジェクトに属さないので、この規則の対象外とした（[ADR 0187](0187-standalone-reads-user-policy-file.md)）。

## 決定

1. エージェントハーネスが使う提供者、モデル、ベースの URL は、一般的なハーネスと同じく、設定ファイルに書く。設定ファイルの形式は TOML とする。モデル以外のエージェントハーネスの設定も、このファイルに書く。
2. 設定ファイルには、提供者を複数書ける。そのうち一つを既定の提供者とし、起動のときのオプションで、名前を指定して別の提供者に切り替える。
3. 役割ごとにモデルを分けること（スクリプトを書くモデルと、診断を説明する軽いモデルなど）は、今回は対象外とする。
4. 利用者単位の設定ファイルは、利用者の設定であり、プロジェクトに属さない。ADR 0187 の方針のファイルと同じく、決まった場所に置き、作業ディレクトリやスクリプトの場所から探さない。

本 ADR は、次の点を決めない。

- ファイルの名前と置き場所、欄の名前、切り替えのオプションの名前、モデルだけを起動のときに変えるオプションを設けるか、ADR 0187 の方針のファイルと同じファイルにするか（[OPEN-102](../open-issues.md#open-102)）。
- プロジェクトごとの設定ファイルを設けるか、設けるなら書ける欄と利用者の設定との重ね方（[OPEN-102](../open-issues.md#open-102)）。
- API キーの書き方と保管（[OPEN-101](../open-issues.md#open-101)）。

## 検討した代替案

- **起動のときのオプションだけで指定する**: 設定ファイルが要らない。しかし、提供者ごとのベースの URL やキーの参照を、起動のたびに書くことになる。
- **環境変数で指定する**: 既存の道具と揃えやすい。しかし、複数の提供者の設定と既定の提供者を表しにくく、シェルの設定に書いた値は、そのシェルから起動したどのプロセスも読める。

## 帰結

- 設定ファイルの形の例は、[エージェントハーネス](../06-tooling/06-08-agent-harness.md)の「設定ファイル」に載せる。欄の名前は仮である。
- 利用者単位の設定ファイルを読むことは、[CLI](../06-tooling/06-01-cli.md)の「処理系は、プロジェクトの設定ファイルを読まない」に反しない。プロジェクトごとの設定ファイルを設けるときは、その規則との関係を [OPEN-102](../open-issues.md#open-102) で決める。
