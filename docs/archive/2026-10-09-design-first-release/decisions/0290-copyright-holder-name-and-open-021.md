# 0290. 著作権表示の名前を `tecogonaz` とし、ランタイムの例外をスクリプトを埋め込んだ実行ファイルの設計に移して OPEN-021 を決着させる

- 状態: 採択
- 日付: 2026-09-30
- 関連章: [ロードマップ](../00-overview/00-03-roadmap.md), [配布形態](../05-platform/05-01-distribution.md)
- 関連する未決事項: [OPEN-021](../open-issues.md#open-021)

## 背景

処理系・標準ライブラリ・同梱の Agent Skill・言語の文書・設計書のリポジトリのライセンスは `MIT OR Apache-2.0` であり（[ADR 0003](0003-license.md)）、著作権表示は `Copyright (c) 2026 <設計者の名前> and Benitoite contributors` とした（[ADR 0242](0242-copyright-notice-for-llm-generated-code.md)）。[OPEN-021](../open-issues.md#open-021) には、次の二点が残っていた。

- 著作権表示の `<設計者の名前>` の書き方（本名か、公開の名前か）。公開の前に設計者が決める。
- スクリプトを埋め込んだ実行ファイルについて、ランタイムの例外を設けるか。その機能を実装するとき（正式リリース版の前。[ADR 0175](0175-script-embedded-binary-before-stable-release.md)）に決める。

初回リリース版の実装プラン（U4）の作業の文書は、`LICENSE-MIT` と README の著作権表示に `<設計者の名前>` を仮に残す形で書いていた。設計者は、名前の書き方を決めた（2026-09-30）。

## 決定

1. 著作権表示の `<設計者の名前>` は `tecogonaz` とする。著作権表示は `Copyright (c) 2026 tecogonaz and Benitoite contributors` となる。`LICENSE-MIT` と、リポジトリの README の著作権表示に使う。
2. スクリプトを埋め込んだ実行ファイルのランタイムの例外は、OPEN-021 の対象から外し、その実行ファイルを設計するとき（[ADR 0175](0175-script-embedded-binary-before-stable-release.md)）に、埋め込む形とあわせて決める。
3. 1 と 2 により、OPEN-021 を決着とする。

## 検討した代替案

- **本名で書く**: 権利者を特定しやすい。しかし、設計者は `tecogonaz` の名前で書くことを選んだ。
- **ランタイムの例外を OPEN-021 に残す**: 論点が一か所にまとまる。しかし、判断の材料（埋め込むのがソースかコンパイル済みプログラムか、実行ファイルに含む処理系の部分）は、その実行ファイルの設計で初めて決まる。初回リリース版の範囲にその実行ファイルはないので、公開の前に決める必要のある名前の書き方と一つの項目に並べておく理由はない。

## 帰結

- [ロードマップ](../00-overview/00-03-roadmap.md)の「利用する既存の OSS のライセンス」と、[配布形態](../05-platform/05-01-distribution.md)の「ライセンスの表示」の著作権表示を、決定 1 の形に改める。
- 実装プランの D30（`LICENSE-MIT`）と D33（README）は、決定 1 の著作権表示を書く。`<設計者の名前>` を仮に残す手順は要らなくなる。
- ランタイムの例外は、[配布形態](../05-platform/05-01-distribution.md)の「ライセンスの表示」に、スクリプトを埋め込んだ実行ファイルの設計で決めることとして残す。
