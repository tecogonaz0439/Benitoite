# 0312. エフェクトの操作の型パラメータに、型クラスの制約を書けなくする

- 状態: 採択
- 日付: 2026-10-04
- 関連章: [構文](../01-spec/01-02-syntax.md)、[型システム](../01-spec/01-06-type-system.md)、[型検査器](../02-impl/02-05-typechecker.md)
- 関連 ADR: [ADR 0118](0118-effect-handlers.md)、[ADR 0158](0158-type-classes-by-dictionary-passing.md)、[ADR 0297](0297-builtin-constraints-in-core-and-op-type-substitution.md)、[ADR 0311](0311-no-type-constructor-params-in-operations.md)

## 背景

操作の型パラメータには、関数の型パラメータと同じく制約を書けた。組み込みの制約（`equality`・`key`）は、コア計算（01-12）が `handle` の節の本体を「操作の型パラメータを宣言の制約とともに加えた Δ」で検査すると定めており、節の中で使える（ADR 0297）。組み込みの制約は辞書を持たないので、実行の規則にも影響しない。

一方、型クラスの制約は辞書の引数で実現する（ADR 0158）。操作の型パラメータに型クラスの制約を付けると、節の本体はその辞書を必要とする。しかし、操作の呼び出しから節へ辞書を渡す規則は、コア計算（E-Op・C-Handle）にも、型検査・脱糖・ハンドラの実行の設計と実装プランにもない。実装プランの F09 の実装担当（Codex）が、操作の型パラメータの制約を節で使う口がないことを報告して止まり、この抜けが分かった。

標準ライブラリのソースと仕様の例には、型クラスの制約を持つ操作が一つもない。

## 決定

1. エフェクトの操作の型パラメータには、組み込みの制約（`equality`・`key`）だけを書ける。型クラスの制約は書けず、構文解析器が E0510 で報告する（鍵 `trait_constraint` の注記）。
2. 組み込みの制約を付けた操作の型パラメータは、`handle` の節の中で、その制約を持つほかの何とも等しくない型として扱う（01-12 の Δ、01-06 の「組み込みの制約（初回リリース版）」のとおり）。

## 検討した代替案

- **操作の呼び出しで辞書を節へ渡す規則を加えて許す**: 言語の表現力は保てる。しかし、コア計算の規則と形式化（`formal/`）、型検査（F09）、脱糖（F11）、コア IR の検査（F13）、ハンドラの実行（R20）を設計し直す必要があり、手戻りが大きい。使う例もない。設計者は禁止する本案を選んだ。禁止は後で緩めても既存のプログラムを壊さない。

他の言語の扱いを、2026-10-04 に一次資料で確かめた。エフェクトを言語の構文として持つ言語の多くは型クラスを持たないので、この問題は起きない。許す案は、操作をデータの構成子として扱う Haskell の方式に当たる。

- Unison は型クラスを持たない（[Unison の FAQ](https://www.unison-lang.org/docs/usage-topics/general-faqs) は「No, or at least, not yet」と述べる）。OCaml 5・Eff・Effekt も型クラスを持たないが、それを明言した一次資料は確かめていない。
- Koka は型クラスを持たず、代わりにコンパイラが解決する暗黙の引数（`@implicit/show` の形。v3.2.0 から）を持つ（[Koka の文書](https://koka-lang.github.io/koka/doc/book.html)）。暗黙の引数を操作と組み合わせたときの扱いは確かめていない。
- Haskell（GHC）では、型クラスの文脈を持つ GADT の構成子（`MkSet :: Eq a => [a] -> Set a`）は辞書を隠れた欄に持ち、パターン照合でその辞書を取り出せる（[GHC User's Guide「GADT 構文」](https://downloads.haskell.org/ghc/latest/docs/users_guide/exts/gadt_syntax.html)、[「存在型」](https://downloads.haskell.org/ghc/latest/docs/users_guide/exts/existential_quantification.html)）。エフェクトのライブラリは操作を GADT の構成子として宣言するので、この仕組みが、本案で欠けていた「操作の呼び出しから節へ辞書を渡す規則」に当たる。ライブラリが制約付きの操作を実際に使う例は確かめていない。

## 帰結

- 01-02「エフェクトの宣言とハンドラ（初回リリース版）」、01-06「エフェクトの宣言とハンドラの型付け（初回リリース版）」、02-05「型とエフェクトの表現」の型パラメータの行に制限を加える。
- 実装プランの 10-02 と `src/diag/codes.rs` の E0510 に鍵 `trait_constraint` を加える。構文解析器の変更と、節の中で組み込みの制約を使う型検査の変更は F09 が行う。
