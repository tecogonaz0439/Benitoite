# 0231. 同梱の Agent Skill は、実行の前に `main` のエフェクトを利用者に示させ、書き込み・外部コマンド・ネットワークは確かめてから実行させる

- 状態: 採択（テストの手順と確認の対象を [0249](0249-skill-test-procedure-without-check.md) で改めた）
- 日付: 2026-09-29
- 関連章: [Agent Skills 対応](../06-tooling/06-06-agent-skills.md), [セキュリティモデル](../07-quality/07-01-security-model.md), [エフェクト](../01-spec/01-07-effects.md)
- 関連する未決事項: [OPEN-015](../open-issues.md#open-015), [OPEN-055](../open-issues.md#open-055)

## 背景

利用者の主な接点は、実行前にスクリプトが行いうること（エフェクトと権限）を確認し、実行後に結果を確認することである（[目的と設計原則](../00-overview/00-01-goals.md)の「想定する利用者と接点」）。初回リリース版は、実行時の権限制御、実行前の権限の表示、OS のサンドボックスを持たない。スクリプトは、処理系を起動した利用者の OS の権限で行える操作をすべて行え、隔離は処理系を起動する側に委ねる（[ADR 0177](0177-server-mode-after-first-release.md)、[ADR 0179](0179-threat-model-and-server-mode-premise.md)）。

一方、初回リリース版の静的検査は、組み込みの細かいエフェクト（`File.Write`・`Process.Run` など）を区別し、型のエフェクトに含まない組み込みの操作を行わないことを保証する（[ロードマップ](../00-overview/00-03-roadmap.md)の「各マイルストーンで宣言する保証」）。`main` の `uses` に書いたエフェクトは、検査を通ったスクリプトが外部に行いうる操作の種類の全体である。

エージェントのハーネスの多くは、シェルのコマンドを実行する前に利用者の承認を求められる。しかし、承認の画面に出るのは `benitoite run report.bnt` のようなコマンドラインであり、スクリプトが何を行うかは分からない。

## 決定

1. 同梱の Agent Skill の `SKILL.md` に、実行の前の確認の手順を書く。エージェントは、スクリプトを初めて実行する前と、`main` のエフェクトが前に利用者に示したときより増えたときに、`main` の `uses` のエフェクトを、利用者に分かる言葉で示す（「ファイルを書き換える（`File.Write`）」「外部のコマンドを起動する（`Process.Run`）」など）。
2. 書き込み（`File.Write`）、外部コマンドの起動（`Process.Run`）、ネットワーク（`Http.Connect`・`Http.Listen`）のエフェクトを含むときは、実行の前に利用者に確かめる。
3. `SKILL.md` には、初回リリース版の処理系は実行中に操作を制限しないことを書き、エージェントのサンドボックスの中で実行することを勧める。
4. エフェクトを読むことは、`main` のシグネチャを読むことである。処理系に、権限を表示する機能は加えない。

## 検討した代替案

- **ハーネスの承認だけに頼る**: Skill の手順が短くなる。しかし、ハーネスの承認の画面はコマンドラインしか示さないので、利用者はスクリプトが何を行うかを知らずに承認することになる。利用者が許可する操作を理解できること（設計原則 3）を、初回リリース版の範囲で満たせない。

## 帰結

- エフェクトは操作の種類だけを表し、どのファイルやコマンドを対象にするかは表さない。対象を確認できるのは、サーバモードの実行時の権限制御を加えてからである（[OPEN-055](../open-issues.md#open-055)）。
- この手順を守るかはエージェントに依存し、処理系は強制しない。手順は、利用者が操作を理解するためのものであり、隔離の代わりにはならない。
- `main` に `uses IO.All` と書くと、どの細かいエフェクトを使うかが示されない。`SKILL.md` は、`main` の `uses` に細かいエフェクトを並べて書くよう指示する。
- サーバモードを加えたときは、実行前の権限の表示（[OPEN-015](../open-issues.md#open-015)）とあわせて、この手順を見直す。
