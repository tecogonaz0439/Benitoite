# ロゴの選定

- 作成: 2026-10-03
- 扱い: 検討用のメモ。初回リリース版の完成後に、設計書（配布や文書の章、ADR）へ移すかを決める。
- 成果物: [brand/](brand/README.md)（SVG と PNG、色の一覧、書き出しのスクリプト）

## 設計者の決定（2026-10-03）

| 用途 | 採用した案 |
|---|---|
| ライトテーマのロゴ | 案 A（三角の結晶） |
| ダークテーマのロゴ | 案 D（蛍光） |
| ワードマーク（ロゴとは別の場面で使う） | 案 E。ライトとダークの両方を用意する |
| アイコン | 案 A と案 D の結晶を、文字なしで別に書き出す |

キャラクター（マスコット）の案は、二度作ったが、すべて採らない。

## 候補にした案

ロゴの案は、鉱物のベニトアイトの性質から作った。

| 案 | 名前 | 形 | 結果 |
|---|---|---|---|
| A | 三角の結晶 | ベニトアイトに特有の三角の結晶を上から見た形。面を三つの濃さの青で塗る | ライトテーマに採用 |
| B | 二色性 | 見る向きで青と無色に色が変わる性質（二色性）を、六角形の左右で表す。中に B | 採らない |
| C | λ の結晶 | A の結晶に λ を刻み、関数型の言語であることを示す | 採らない |
| D | 蛍光 | 短波の紫外線で青白く光る性質を、暗い地の上の光の輪で表す | ダークテーマに採用 |
| E | ワードマーク | 「benitoite」の二つの i の点を小さな結晶に置き換えた文字だけの形 | 別の場面で採用 |

キャラクターの案は、次の二回を作った。

- 1 回目: 東アジアにいる動物（狛犬、狐、月のうさぎ、龍、パンダ）。設計者の意図（東アジアでよく描かれる型のゆるキャラ）と違ったので作り直した。
- 2 回目: 日本・韓国・中国でよく見るゆるキャラの描き方（二頭身、点の目、頬の色、太く均一な輪郭）で、動物（ラッコ、ねこ、ナマケモノ、ハリネズミ、カンムリウズラ）をモチーフにした。すべて採らない。

## 書き出したもの

- SVG: ロゴ（A・D）、結晶のアイコン（A、D の地付きと地なし）、ワードマーク（E のライトとダーク）。文字は Sora（太さ 600）を輪郭に変換して埋め込んだので、閲覧する環境に書体は要らない。Sora は SIL Open Font License 1.1 で配られている。
- PNG: アイコンは 16〜1024 px の正方形、ロゴとワードマークは幅 800 px と 1600 px。
- ファイルの一覧と色は [brand/README.md](brand/README.md) に記す。

## 残っていること

- 似た商標やロゴがないかを確かめる【要検証】。
- 使う場所を決める。候補は、ウェブサイトのトップ、リポジトリの README、ファビコン、文書（`docs/reference/` など）の見出し。
- 清書をデザイナーに頼むかを決める。今のファイルは図形を組み合わせて描いたものである。
- 設計書に移す場合は、ファイルの置き場所（リポジトリの中か、ウェブサイトのリポジトリか）と、ライセンス（処理系と同じにするか、商標として扱うか）を決める。
