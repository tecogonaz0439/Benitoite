# N18 実装の記録

## テストの作成時の関門

1. 名前付き引数の値と穴、関数型の実名と Legacy の仮名、その位置と個数を解析で保持する契約を確認する。整形ではラベルから値までを一つの要素として字下げし、字句とコメントを保持する。名前解決ではラベルを参照や束縛にせず、値と型だけを解決する。脱糖は対応表のない名前付き引数を実行可能な位置呼び出しへ変換しない。
2. ラベルの位置を値の位置で上書きする、穴を通常の式にする、旧型の仮名を欠落させる、ラベルを未定義の値として解決する、型内のラベルを字下げし損ねる退行で失敗する。一般入力で新構文を早く受理する退行も診断の比較で検出する。
3. 既存の入力とテストには Arg::Named と明示名の FnType がない。解析補助の単体検査で構文を確認し、独立した危険のある名前解決とフォーマッタの境界を追加で確認する。既存の旧入力の検査は維持する。
4. 公開の解析入口・実行入口・フラグは追加しない。計画で指定された非公開の解析補助は一般経路への接続までテストのビルドで検査し、フォーマッタと名前解決には AST を与える。テストのために公開範囲を広げない。

## 変更

`Arg::Named(Box<NamedArg>)` と値・穴の `ArgValue`、`FnType.param_names` と `names_origin` を追加した。`ContractOrigin` は AST に定義し、types から再公開した。旧注釈は型の個数と同じ長さの `arg1` 以降の仮名を持ち、元の型の位置を保つ。

解析補助で名前付きの値・穴と、入れ子を含む名前付き関数型を保持する。一般の引数・型注釈の入口は旧経路のままとし、E0201 などの既存の構文診断を維持した。名前解決はラベルを束縛・参照にせず、関数型の重複名は E0310 で報告する。フォーマッタはラベルから値・型までを要素の範囲とし、字下げとコメントを保持する。

各走査と検査用の AST の走査、移行の索引、旧 corpus の書き出しを新しい列挙子に対応させた。名前の対応表のない呼び出しは型検査で正常な位置呼び出しとして扱わず、脱糖でも InternalError で拒否する。E0310 の説明を関数型へ広げ、gen_skill で参照文書を再生成した。公開されている文法の生成物には新構文をまだ載せない。

実装中に、関数型の仮名と型の並びの組み立てを再帰の枠内に置いたため、既存の通常スタックでの深さ上限テストがスタックを使い切った。組み立てを `finish_fn` へ分けて修正した。既存の深さ・期待値・スレッドのスタックサイズは変えていない。既存の assert・期待値・ignore は維持した。

## 計画の補正と申し送り

準備中の解析補助のビルド範囲と ContractOrigin の定義場所は decisions.md の R46 に記録した。公開の解析モード、一時的な診断コード、表外の公開シグネチャの変更はない。

N19 は新しい型注釈を一般経路へ接続し、静的な型に名前と出どころを保持する。N21b は `parse_named_arg` の `cfg(test)` を外して一般の呼び出しへ接続し、対応表の作成・型検査・脱糖を同時に実装する。名前付きの穴とパイプは N23 で接続する。未移行の入力の診断を変えず、準備中の拒否を名前を捨てる処理へ置き換えないこと。
