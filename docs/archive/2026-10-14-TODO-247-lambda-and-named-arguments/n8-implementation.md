# N8 実装記録

## 範囲

`NamedSurface/Syntax.lean`・`Typing.lean`・`WellFormed.lean`・`Desugar.lean` に、旧表層の全構文・宣言・判断・脱糖を名前付き共有型で追加する。旧表層、旧交換形式、Rust の本番コードとテストは変更しない。

通常呼び出しはソース順のラベルと契約位置を持つ。`CallOk` は名前の整形式、ラベルと位置の一致、全位置の指定、重複と範囲外の排除、単一位置引数の制限を検査する。パイプは位置 0 を先に占める。`HoleArgs` の各要素はラベルと位置を持ち、穴の名前・型をソース順に取り出す。固定式と callee は生成ラムダの本体で評価する。直接構成子の穴には宣言位置から `argN` を付ける。

脱糖は callee とソース順の式を元の順で束縛し、最後に参照だけを契約位置順に並べる。辞書とメソッドの直接呼び出し、操作、レコード、制御、コレクション、return・try・ハンドラの既存の規則も維持する。取り出す関数の引数名は `value`、辞書の内部名は `%dict1` からの並びである。

## 例を追加する前の関門

1. 守る契約は、名前・位置の対応と拒否、通常呼び出し・穴・パイプ・操作・メソッドの型付け、callee の先行評価、ソース順の束縛、参照の並べ替え、穴の遅れた評価と名前の順である。
2. ラベルを無視して渡された位置を信用する変更、位置 0 の重複の見落とし、宣言順への式の並べ替え、穴の契約順への並べ替え、パイプの左辺や辞書の変数番号の誤りによって、独立した型付け・脱糖結果の例が失敗する。
3. 旧モデルは名前・位置の情報を持たず、これらの退行を検査できない。新しい表層の型付け・脱糖の境界で、具体的な入力と手で定めたコアの計算・契約を比較する。Rust の重複テストは追加しない。
4. テスト専用の差し込み口は追加しない。型付けは本物の判断と宣言を使い、脱糖結果の期待値は脱糖器から生成しない。
