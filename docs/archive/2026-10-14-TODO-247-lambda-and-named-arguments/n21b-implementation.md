# N21b 実装の記録

## テストの作成時の関門

1. 一般の解析・実行の入口で、名前の診断、呼ぶ式の先行評価、逆順の明示引数のソース順、途中の脱出、末尾呼び出しと確保の契約を守る。交換の境界では、新入力が旧形式に入らず、依存宣言を含む新形式で独立検査されることを守る。
2. ラベルの解析漏れ、ラベルを局所参照にする変更、引数の計算自体を宣言順へ動かす変更、脱出後の引数の実行、末尾呼び出しの通常呼び出し化、新入力の除外で失敗する。
3. 準備済み AST の検査は一般 parser の接続を通らないため、通常呼び出しの交換の検査を実際の名前付きソースへ移す。CLI の新しい入力は出力・診断・終了状態と参照インタプリタとの一致を検査する。確保と独立した Lean の比較は各境界に固有の保証であり、CLI の出力だけでは検出できない。
4. 既存の公開入口・ゴールデン・交換の補助だけを使う。本番にテスト専用の公開範囲・フラグ・引数を加えない。

## 実装と検査

通常の名前付き値を一般の引数解析へ接続した。ラベルを名前解決の参照にせず、既知の契約の対応表を型検査・脱糖・実行へ渡す。名前付きの穴とパイプ右辺はまだ一般の解析へ接続しない。parser のパイプの右辺の結合力を使って後者を区別する。レコードとして解析された直接のデータ構成子は record_call_name で束縛の種類を確かめ、ラベルの位置に E0456 を出す。準備用の record の入口は本番でも使い、テスト専用の転送の関数は残さない。

名前付き呼び出しの子だけでは先に束縛した局所のラムダの Legacy が残るため、その呼び出しを含む関数本体を新しい境界として先に走査する。実名を Known として保持し、旧本体だけの適合は保つ。ラベルから未確定の契約順を作らない。この補正は decisions.md の R55 に記録した。

一般入力をプログラム単位で振り分け、名前付き引数を含む追加入力を corpus 8・型表 2・網羅性 2 に書き出した。新入力を corpus 7 に渡したり、Legacy の型を新形式へ読み替えたりしない。逆順の指定のラベル・式・CallPlan の位置をソース順で保つ。Console で実行順を観測する入力では組み込み操作表にも names が必要であるため、OpDef と Scheme の実名の一致を確かめて出す。空の表を用いる案は採らず、R56 に記録した。

CLI の追加した 4 入力は、callee → b → a の順と値の配置、局所のラムダ、return・try による脱出、途中のゼロ除算で後の引数を実行しないこと、逆順の指定を伴う 10 万回の末尾再帰を検査する。CLI の二方式・コア IR・参照インタプリタ・整形の既存の境界で検査した。ゼロ除算の新しい期待値は R0101・除算式の範囲・main のトレースを明示して作り、実行からの一括更新は行っていない。確保の検査には、既存の fib の assert を保ったまま、名前付きの末尾呼び出し 100 回と 10,000 回での確保数の差の上限 16 を加えた。

一般の入力から未知・重複・不足・混在・型不一致・高階の名前不一致・構成子の名前指定の診断を検査した。子の独立した型の誤りと未知のラベルを両方保ち、誤記の構成子と真のレコードの診断も区別する。診断コードの一覧と主位置は厳密に比較する。旧の準備用の f(item: 1) は仕様により成功へ変わるため、design.md の負のテストの対応表に記録した。元の解析の assert とコロンの位置の比較は、未接続の穴とパイプで保つ。既存の assert の削除・期待値の緩和・ignore の追加はない。

N21a の通常呼び出しの検査は AST へのラベルの後付けをやめ、実際の名前付きソースから型検査・脱糖の出力を得る形へ移した。CallPlan・ラベル・位置・引数順・宣言数・名前を持つ網羅性の型の既存の assert は保った。独立した静的な穴と挿入の入力、N19・N20 の最小入力も維持した。新旧の識別子・版・件数と片方だけへの振り分けを [manifest](n21b/exchange-manifest.json) で確かめる。旧の単件の surfaceCheck も通常の位置指定の入力へ接続し、check-formal.sh でバイナリをビルドする。

Skill の説明の実際の生成元である src/cli/tools/skill/generate.rs に、基本の EBNF に加えて受理する名前付きの値と関数型の書き方、ソース順、名前の契約と診断、移行中の穴・パイプの制限を加えた。gen_skill で生成物を作り直した。基本の規則の数と見出しは変えていない。

本番の Rust は追加 132 行・削除 20 行、テストと入力・交換の補助は追加 567 行・削除 34 行である。内訳は [line-counts.json](n21b/line-counts.json) に記す。公開の型・シグネチャと Lean のソース・規則・定理は変更していない。コミット、docs/todo の変更、scripts/check.sh（dry-run を含む）、gc-stress 構成の検査は依頼に従って行っていない。
