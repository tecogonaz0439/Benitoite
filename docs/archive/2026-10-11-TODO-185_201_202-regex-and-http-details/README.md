## 扱う項目

docs/todo は非公開のリポジトリなので、項目の本文を `todo-items.md` に写した。要点は次のとおりである。

1. docs/todo の TODO-201「繰り返す照合を一致ごとに区切り、取り消しと中断を効かせる」。`Regex.findAll`・`replaceAll`・`replaceAllWith`・`split` の照合が VM の中で同期的に走るので、長い入力では `Task.withTimeout` の取り消しも中断の要求も効かない。
2. docs/todo の TODO-202「HTTP サーバの細部の残り」。応答から除く接続ごとのヘッダ、パスが空の `OPTIONS` の絶対形、要求の対象の `#`、`100-continue` の書き込みの準備を待つ経路のテスト。
3. docs/todo の TODO-185 のうち `Regex` の確保の上限の点。`findAll` のグループの確保、`compile` の誤りの文面の大きさ、`replaceAllWith` の計算量。1 で同じ関数を書き直すので、あわせて扱う。TODO-185 のほかの点は扱わない。

## 目的

`Regex` の繰り返す照合の途中でも、取り消しと中断が効き、確保が上限の内で止まるようにする。HTTP サーバの要求と応答の扱いを、RFC 9110・9112 に照らして残りの細部まで揃える。
