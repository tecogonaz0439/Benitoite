## 軽

### L1. E0908 の 0.0.7 の help が、版の数字を固定して書いている

- 場所: `crates/benitoite/src/modules/text.rs:12`（`LOADER_ENVIRONMENT_MIGRATION`）。design.md「E0908 の変更表と 0.0.7」の文言の案も同じ。
- 問題: help に「update the language declaration to 0.0.7」とある。変更表の項目は後の版にも残り、宣言より後の変更をすべて版の順に並べる。このため、たとえば 0.0.8 の処理系が `language "0.0.5"` を検査すると、0.0.7 の項目の help が「0.0.7 へ上げよ」と案内する。しかし 0.0.7 へ上げても 0.0.8 の E0908 が出る。0.0.5・0.0.6 の help は版の数字を含まないので、0.0.7 の項目だけ書き方が違う。今の 0.0.7 の処理系では正しい。
- 修正案: 次に版を上げる改造（0.0.8 の項目を加えるとき）で、該当の部分を「update the language declaration to the current version after reviewing the script」のように版に依らない文にする。または、宣言の更新の案内を、最後の項目の help か E0908 の共通の注記に一度だけ出す。直すときは golden（`older-language.diag.json`）と `modules/tests.rs`・`modules/package.rs` の期待値も同じ変更で直す。今回の公開を止める必要はない。

### L2. CHANGELOG のエフェクトの上限の項で、全体の準備がオプションを付けたときだけであることが読み取りにくい

- 場所: `CHANGELOG.md:24`（Harness interfaces の 3）
- 問題: 「Test execution prepares and checks all selected entries before starting any test; a failure prevents the entire selected set from running.」は、`--allow-effects` を付けた `test` だけに当てはまる。オプションのないときは、従来どおりファイルごとに準備して実行する（`docs/reference/benitoite.md:268` の「Without the option, executing tests retain their usual per-file preparation and execution.」、inspection.md の「With a limit, `test` …」）。項目の中の文なので文脈から推せるが、単独で読むと、`test` がいつもこうなると誤解されうる。
- 修正案: 「With the option, test execution prepares and checks …; without it, files are still prepared and run one at a time.」とする。

### L3. harness-response.md の移行の段落の小さな問題（固定ハッシュの案内、空白、保管後のリンク）

### L4. 日本語訳の細かな言い回し

- 場所と問題:
