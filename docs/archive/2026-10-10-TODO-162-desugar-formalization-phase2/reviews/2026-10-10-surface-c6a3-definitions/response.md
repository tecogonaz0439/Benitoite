# C6a-3 のレビュー結果（Opus）

レビュー担当: Claude Code の Opus 5.5（medium）。

重さが高の指摘はない。脱糖と型付けは 01-12・01-06 を表しており、性質 1 の言明も弱まっていない（`Theorems.lean` は変わっておらず、`#print axioms` は二つの定理とも `[propext, Classical.choice, Quot.sound]`）。

## 指摘

1. （中）01-12 の写しと 07-04 の対応の表が追いついていない。01-12 の 21 行は「脱糖だけで表すもの…は本章を正とする」と書くが、定数の脱糖は形式化し性質 1 を証明した。表層の型付けの箇条書きに `E_Const` がない。07-04 は定数を「対象外」のままにしている。01-12「トップレベルの定数」の「`⟦e⟧` はどこで評価しても同じ値を返して終わり」は 01-06 の検査に基づく主張で、表層の型付けでは保証されない（形式化の範囲の外）が、そのことをどこにも書いていない。直し方: 21 行を「段階 C6 で形式化したもの（定数を含む）は Lean を正とする」に改め、箇条書きに定数の参照の規則を加え、07-04 で定数を段階 C6 の行へ移して 01-12 より広い点（定数式の種類の制限を検査しない、実行時エラーと `Map.fromList`・`Set.fromList` の重複を検査しない、R を保つので `return`・`try` を含む本体にも型が付く、注釈の型に使う位置の型変数を許す、循環しないことは入力の前提）を記し、「どこで評価しても同じ」は性質 1 の対象外と添える。
2. （中）C6c-3 で `ConstRef` を置き換える位置と変数の番号を先に決める必要がある。処理系の脱糖は参照を計算 `Return(ConstRef k)` として作り、ほかの部分式と同じく `let` に束縛するので、`Return(ConstRef k)` 全体を定数の本体の計算で置き換えれば Lean と同じ形になり、正規化は要らない見込みが高い。注意点として、`const_def` は `State::new` で変数の番号を 0 から振るので本体の番号は使う位置の関数の番号と重なり、`exchange.rs` の値の変換は `ConstRef` が任意の値の位置に現れうる形をしている。直し方: 本体は使う位置と独立に空の環境で番号に変換してから埋め込む（閉じているのでずらしは要らない）。書き出しで `ConstRef` が `Return` の直下にしか現れないことを確かめ、ほかの位置なら対象外として数える。本体の型の書き出しでは使う位置の `type_order`・`clause_types` を引き継がない。
3. （中）同じ定数のすべての参照に同じ注釈と本体が入ることを書き出しの構造で保証し、入れ子の参照で大きさが指数的に膨らむのを避ける。直し方: 交換の形式に名前で引く定数の表（名前 → 注釈の型、本体）を持たせ、表層の参照は名前だけを書き、`Convert.lean` が表から一度だけ作った `.constE ty body` を各参照に入れる（循環は展開中の名前の集合で検出して失敗させる）。同じ表から処理系側の `ConstRef` も展開すれば、比べる両側の出どころが揃う。
4. （低）`Syntax.lean` の `Expr.Exits` の `constE` の場合のコメント「定数の本体には return を書けない」は、形式化した入力（R を保つので `returnE` や `try` に型が付く）と合わない。`False` という定義は安全な側にある。直し方: 「ソース言語の定数式は return を含まない。形式化では R を保つので型が付く場合もあるが、名前の参照として辿らない」に改める。
5. （低）本体を R = none で検査する案（`lazy` と同じ）は、`Release` に R を変える補題がないので採らなかった、と P5 か改造の文書に記録する。今の形でも性質 1 は偽にならない。
6. （低）範囲の条件が注釈の型に使う位置の型変数を許している（01-06 は定数の型を具体的な型に限る）。性質 1 には影響しない。閉じた形にするなら単調性の補題を確かめてから変える。変えないなら 07-04 の「広い」の列に記す。

## 観点ごとの結論

1. 脱糖と型付け: 問題なし（処理系の `const_def` の `Position::Other` とも一致する。範囲の条件（値の変数 0 個）は `constant_cannot_capture` で確かめてある）。
2. 広くなった点と性質 1: 問題なし（記録は指摘 5・6）。
3. 弱化の証明と言明: 問題なし。
4. C6c-3: 指摘 2・3。
5. 01-12 の写し: 指摘 1。
