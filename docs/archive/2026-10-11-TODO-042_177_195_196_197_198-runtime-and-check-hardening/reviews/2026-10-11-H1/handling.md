# 作業 H1 のレビューの所見の扱い

| 所見 | 扱い |
|---|---|
| 1. CONNECT への 205 に `content-length: 0` を送る（要修正） | 直した。CONNECT への 2xx の規則を状態の規則より先に当て、単体テストの期待値を直した（Codex の追加の作業） |
| 2. `write_if_room` の使わない引数 | 直した。引数を消した |
| 3. 失敗の変換の写し | 直した。`output_write_failure` と `output_written` に切り出した |
| 4. コメントの根拠 | 直した。設計書の節と RFC の条を添えた |
| 5. 待ちの途中の不正な応答の誤りの種類 | 直した。`check.sh` で既存の統合テスト `http_exchange_release` の `runtime_error_after_partial_response_finishes` が R0701 を期待して落ちたので、別のタスクの呼び出しは再開とせず、引数の検査を先に行う形に戻した（オーケストレータ） |
| 6. HTTP-03 の確かめの経路 | 直さない。分岐が短く読めば分かる |
| 7. 統合テストの表の重なり | 直さない。完了の条件が生の TCP での確かめを求めている |
| 8. 設計書と CHANGELOG | 改造の反映（作業 D）で直す。CONNECT と 205 の優先順位も 03-09 に書く |
