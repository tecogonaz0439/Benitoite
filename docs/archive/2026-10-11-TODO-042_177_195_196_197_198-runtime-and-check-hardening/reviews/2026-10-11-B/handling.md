# 作業 B のレビューの所見の扱い

すべて Codex の追加の作業で直した。

| 所見 | 扱い |
|---|---|
| 1. ガードの写しで判定の木の予算を抜けられる | 直した。一つの `match` の予算に加えて、定義ごとに 0 に戻さない合計の予算（2,400,000）を設けた。外側 10・内側 10 の入力は release で 0.075 秒で L0112 になる |
| 2. 辞書の予算が型の大きさを数えない | 直した。部品ごとに 1 と写す型の節の数を足し、上限を 32,768 にした。所見の d=13・w=300 の入力は E0715 になる（辞書の制約を外した対照も release で約 3 秒かかり、残りは辞書と関係のない検査の時間） |
| 3. 判定の木の予算が行列の幅を数えない | 直した。行列のセルの数で数え、一つの `match` の上限を 600,000 にした（長さ 1,024 のリストのパターンの既存のテストが通る余裕） |
| 4. L0112 の注記 | 直した。一つの木と定義全体の場合で文を分けた |
| 5. コメントの設計書の参照 | 直した |
| 6. 差分テストの除外 | 直した。期待する終了状態が 2 で、期待する診断に L のコードがある場合に限った。`tests/verify.rs`・`tests/random_programs.rs` も同じ条件にした |
| 7. E0715 の重複 | 直した。一つの使用で一度出したら残りの制約を解決しない |
| 8. 予算の境の値 | 直さない |

測り直した手元のソースの最大は、辞書 14、一つの `match` 51、一つの定義 126 で、上限はそれぞれ約 2,341 倍・11,765 倍・19,048 倍である。
