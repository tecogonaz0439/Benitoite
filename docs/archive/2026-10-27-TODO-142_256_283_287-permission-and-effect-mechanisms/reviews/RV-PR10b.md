# RV-PR10b: R 段の計画の修正（PR10b）の再レビュー

2026-10-28。対象は PR10b で29枝に組み直した `plan-r10-r40.md` と、[RV-PR10](RV-PR10.md) の「対応」の表。独立レビューの担当が読み取りだけで行った。結論: RV-PR10 の15件はすべて本文まで直っている。組み直しで新しく中2件・軽8件が生じた。重大はない。

## 中1: R10.7 の新形式の書き出しは、K10.1 まで Lean のどの読者も受け付けない。「影響する書き出し元の版」が特定されていない

- 箇所: R10.7 の手順「影響する書き出し元の版も15/7に上げ」、前提の第4段落、表「K10 までの全比較の不一致」。
- 問題: work は Lean を呼ばない（`formal_build` の `lake build` だけ）ので、R10.7 の枝の末尾のコンパイル・lib 全件・統合テストは通るが、出力を読める Lean の読者はない。corpus 15 は入力ごとに `scopeAcceptance` が必須（`formal/Benitoite/Exchange/Version.lean` 182〜183行）、corpus と sidecar の版は組で照合される（`BuiltinCheck/Main.lean` 155行、`SurfaceCheck/Main.lean` 71行）ので 14/7 の組も読めない。新版は旧版からの補完を通さないので `ix`・`ranges` も必須（Version.lean 225〜229行）で、呼び出しの `ranges` は R20.3 まで書かれない。区間の書き出しは `exchange::named_type`・`named_builtin_tables` を共有する（`tests/desugar_export/interval.rs` 346・533行）が `surfaceVersion` は 14 のまま（interval.rs 583行、`interval/prepare-range.py` 72行）で、Lean は版14の中の範囲の欄を拒否する（`Interval/Exchange.lean` 727〜729行）。版は `desugar_export.rs` 171・354・363・368・458〜470・806・853・967・1033行、`lib.rs` 130行、`named.rs`、`check_named.py` 178行、manifest の namedVersions に固定値で書かれている。R10.7 の取り込みから K10.3 までの約20枝の間 `check-formal.sh` は失敗し、rvar・rkinds・shape の形式の誤りも K10.1 まで見つからない。
- 修正案: R10.7 に変える書き出し元と版の定数の一覧を置き、R10.7 と K10.1 で上げるものを分ける。「R10.7 の取り込みから K10.3 まで check-formal は失敗が見込まれ、それ以前の成功は引用できない」と明記する。R10.7 で B-Lean と builtinCheck／desugarDiff による局所の読み込みを一度行う（テスト専用の corpus、`scopeAcceptance` は空の patterns・hosts）か、検出の遅れを K10.1 の見込みのリスクとして書く。

## 中2: R20.3 で四入口の静的な型が Top から非 Top に変わる。R20.0a〜R20.2 で書いたテスト・例・設計書の追随の義務がない

- 箇所: R20.3 の対象・手順・完了の条件。
- 問題: R20.0a/.0b の `checkPathIn`・`checkRequestIn` は裸の `PathIn`（Top）を返し、R20.3 からは既知の pattern に非 Top を返す。添字は不変なので、R20.0a〜R20.2 で裸の `Scope.PathIn`／`Http.RequestIn` を注釈に書いたテスト・golden・例・Skill・03-06/03-09 の例は、R20.3 で拒否されるか型が変わる。R20.3 の対象に 03-06/03-09 がなく、棚卸しの義務もない。
- 修正案: R20.3 に四入口の既存の利用（tests・testdata・examples・Skill・設計書）の棚卸しと修正、03-06/03-09 の「静的な範囲は Top」の記述の改訂を加える。あるいは R20.0a/.0b のテストで R20.3 で変わる裸の注釈を書かないことを完了の条件にする。

## 問題がなかった点

- RV-PR10 の15件はすべて本文まで直っている（重大1・中3・軽3 は上の中1・軽3・軽2 で補足）。
