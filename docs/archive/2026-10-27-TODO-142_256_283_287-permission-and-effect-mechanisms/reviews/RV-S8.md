## 中

- 中1（R23）: 節の入口で Top へ忘れると、捕捉した値をそのまま転送する節（記録・転送のハンドラ）の上限が Top になり、狭い uses の関数で使えなくなる。代案: 本体の ε に同じ名前の範囲原子が一つだけあれば、それを節の添字にする（複数・行変数なら Top）。証明は Top の補題を被覆の補題へ一般化すれば済む見込み。
- 中2（R7）: 添字の不変は、利用者の範囲多相がないこと（R14）と組み合わさり、狭い値を広い添字や Top の引数へ渡すたびに Result を返す再検査が要る。代案: 被覆を静的に確かめる明示の拡大の標準関数（失敗しない）。Ty.Le は変えずに済む。
- 中3（R8）: pattern に const を使えるかが書かれていない。先例の `Regex.compile` の直接呼び出しの規則（01-06:203）は const の参照を認め pipe を除く。揃えて R8 に含める。
