## 問題がなかった点

- 全読者の追随: src の `EffectName::` は17ファイル（開始時の56箇所に加えたテストの分を足して62箇所）、tests 3ファイル、examples 2ファイル4パターンで試行 T と一致する。名前だけへ変換して範囲を捨てる箇所、Top へ丸める箇所はない。範囲を見ない照合（コード生成の束縛による識別、E0415 の名前の分類、修正案の別名の探索）は名前の段の判断である。
- 構造の比較: 比較・hash・整列は derive の Eq・Ord・Hash で名前と範囲の両方を使い、重複除去・和・包含、推論側の `Elem`・`includes`・由来の鍵、`effect_key`、脱糖の `without`、IR の handled も構造で照合する。行の代入と Fail の中の関数型の代入が範囲を保つことをテストで確かめている。被覆による削除はない。
- 表現の妥当性: Lean は利用者のエフェクトを含むすべての名前に範囲の位置を持たせ、種類は表のデータの `effKind` で別に決める。Rust の `User(_, Range)` はこの形と一致し、README の Q9 (c) とも矛盾しない。
- Top の互換: CLI 249通りで差0（変更前後で実行ファイルが別であることも記録）、旧版の交換206ファイルが大きさと SHA-256 まで一致し、W-R の後の再照合も差0。旧版の交換の書き出しは Top だけを書き、非 Top では明示的に失敗する。
- R10.1 の残り: `host_mask` の `assert!` は除かれ、シフトの失敗は `Err(InvalidScope::Internal)` を返す。マスクは構築時に計算して保持し、等号と順序は変わらない。
- 規約・設計書・検査の記録: 追加の `unwrap` はテストの中だけ、`as` と lint の免除・`dead_code` はない。02-05・02-06 は実装と一致し、01-07 は変えていない。W-R は初回の clippy の失敗と修正を記録し、check.sh 自身の終了0、外側453.857秒、lib 1,350・統合40ターゲット395件。
