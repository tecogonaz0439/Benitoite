## 読めば確定する問題

### 中1: R ⊆ S を被覆でなく構造の等号で閉じたので、Release の効果の包含が構造上のままであることが前提になった

- 箇所: `Release/Lemmas/PresMain.lean` の `preservationE` の `E_OpPrim` の腕、plan-l10-l50 の注「L30.1 の結果による付け替え」、01-12「ハンドラ」の K-Handle の【決定】。
- 問題: S ≠ Top の場合は、呼び出しの原子 `L[r]` が `Eff.Sub` で穴の効果へ届くことと、穴の効果の L の原子が `L[S]` だけであることから r = S を得て閉じている。これは Release の C-Sub と `Eff.Sub` が構造上の包含だから成り立つ。判断 11 は「R の S への被覆から S への所属を得る専用補題」を予定し、旧の L30.2 の行も「被覆の健全性から導く」だったが、どちらも今の Lean に現れない。表層では上限を被覆で検査する（判断 5・10）。L40.4・L40.5 が被覆による効果の包含を Release に入れると、被覆されるだけの原子は穴の効果に届かず、この議論は成り立たない。表層が保護本体の効果を被覆で整理してから添字を選ぶ場合も、表層の S とコアの規則の値が一致しなくなる。
- 修正案: L40.4・L40.5 の行と停止の表に「Release の効果の包含は構造上のまま」を L30.1 の証明が依存する条件として書く。脱糖の後のコアの保護本体の効果から計算した規則の値が、表層の検査器が選んだ S と一致する補題を L40.5 の完了の条件に入れる。被覆による包含が要ると分かったら停止条件として扱う。判断 11 の専用補題を使っていないことを記録する。

### 中2: 「S を節の本体や出力から逆算しない」は、Lean の宣言的な型付けについては正確でない

- 箇所: `Release/Typing.lean` の `ClauseIxOk`・`ClauseSig`、README の L30.1 の項、01-12「ハンドラ」。
- 問題: 許す添字は Top と規則の値の二つだけで、判断 11 と合う。ただし、どちらで型付けるかは導出が選ぶので、二択の範囲では本体に合わせて選べる。Lean の型付けは判断 11 の型検査器（常に規則の値を選ぶ）より広い集合を型付ける。健全性の定理はその広い集合について言うので結論は弱まらないが、判断 11 の「一意に選ぶ」は L40.5 で型検査器の性質として示すまで Lean にない。Top を許す理由（規則の値だけでは型の代入で保存が成り立たない）の反例は「規則の字面から導いた。Lean では試していない」である。
- 修正案: README と 01-12 を「許す添字は規則の値と Top だけであり、どちらで型付けるかは導出が決める。型検査器が規則の値を選ぶことは L40.5 で示す」に直す。代入の反例は確かめていないと明記する。

### 軽3: `WrongHandleTyped` は「`ClauseSig` だけが違う」より狭いモデルで、SK §4 の形の反例はない

- 箇所: `Release/TargetReachExamples.lean` の `WrongHandleTyped`・`wrong_of_clauseSig`、L30.5 の results、07-04「証明する性質」。
- 問題: `WrongHandleTyped` は節が一つで文脈が空の `handle` に限る。本番の導出から誤った規則の導出が得られることは示しておらず、示しているのは節の操作の型の包含だけである。SK §4 の形（節の効果を出力の上限に含めない規則）は「本番の定義の上では作れない」として置いていないが、`WrongHandleTyped` も本番の定義ではなく、同じやり方で作れる。
- 修正案: 本番の一つの節の `handle` の型付けから `WrongHandleTyped` を得る補題を足すか、記述を「一つの節・空の文脈に限ったモデル」に直す。SK §4 の形のモデルも置く。L50.4 で扱ってもよい。

### 軽4: `ContTyOld` は L30.1 の前の `ContTy` の字面どおりの写しではない

- 修正案: docstring を「節の型付けは新しい関係で読む旧の形」に直すか、`opSig` で書いた写しを置く。L50.3 で整理すれば足りる。

### 軽5: L40.3 の記録は番号ごとに一つあることを示さないので、`analyzeBody_sound` は存在の形にとどまる

### 軽6: 問24 の 7 は、直接の射影の側も既知にならないので、自明に満たされている
