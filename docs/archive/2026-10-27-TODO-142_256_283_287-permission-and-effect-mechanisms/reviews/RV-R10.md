## 問題がなかった点

- 診断の一貫性（段の終わりの版の実入力）: E0519 は同名の原子があって覆えない場合だけ出て、主位置は呼び出し、宣言は副位置。高階関数・ラムダ・endpoint でも出る。同名の原子がなければ E0501 で help の追記の案も正しい。重複は E0419 で両位置。`List[string]` は E0201、`Integer["/data"]` は E0520、`IO.All[...]` と利用者エフェクトへの範囲引数は E0513。`File.Wrte[...]` の E0303 は1件。値型の非 Top の不一致は E0401 で添字は不変。
- 被覆・署名・書き出しの意味の一致: `EffectName::covers` は名前を確かめてから範囲を比べ、`RangeIndex::covers` は固定と変数を覆わず変数どうしは同じ番号だけを覆う（どちらも Lean と一致）。`Covers { outer, inner }` から書き出しの `{"covers":{"inner","outer"}}` まで向きが一貫し、02-05 の向きも直っている。`rvar` は一署名の内側だけに許され `rkinds` の個数で検査される。Top を覆うのは Top だけ、すべて Top の列は許容を満たす。
- 範囲変数が漏れる経路はなく、利用者の構文から `rvar` を作れない。
- 互換: R10.6 の B0 比較の意図した差（E0303 の一覧、拒否例の coverage、内容ハッシュ、k3 の番号）のほかに差は見つからなかった。fmt は字句を保ち空白だけを整える。
- RV-R10.1〜.6 の対応の行き先は中3 の不一致を除き受け持たれている。UB20 の新しい本番修正の依頼は0件。
- 設計書: 未実装の API は 07-04 の形式化の表だけに現れ「Rust は未接続」と添えてある。情報フロー制御の語は 00-04・01-06・01-07・02-05 にない。
- 検査の記録: 各枝の W-R（check.sh 自身の終了0）、初回の失敗と修正、R10.3 の release_stack 3回、short（どれも合図より下）、F-table（builtinCheck・desugarDiff とも終了0、nonTopRanges=18）がそろう。
