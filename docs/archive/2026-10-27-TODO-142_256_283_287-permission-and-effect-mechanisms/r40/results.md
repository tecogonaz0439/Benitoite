## 意図した差

- E0513/E0520 は型と範囲の引数を区別し、E0519 は契約・規則の範囲・理由・由来と、受理に至る修正案を示す。注釈済みの誤った拡大先にも、対応する PathIn または RequestIn だけを案内する。
- effects と aggregateEffects の expanded は従来の名前集合であり、任意欄 bounds に宣言上限の原子を保持する。Top・同名の狭い原子・冗長な宣言も保持し、未知と未完了を空へ変えない。形式の版と受け入れ規則を保つ。
- doc の check/error 例は入口を選ばず空の Effects と空の tests を返す既存の挙動を保ち、その空を純粋な契約と読む説明を訂正した。check/error 例は実行する上限の和から除く。
- 資源停止の主文と失敗理由の確保には実際の File の入口名を渡す。RequestCheckError の標準 Show は加えず、構成子の match で扱う。
- 範囲付き原子と名前だけの照合をハーネスの説明でも区別する。診断の由来や処理済みの利用者名を許可へ戻さず、実行時権限・実体の隔離・情報フロー制御の保証を加えない。
