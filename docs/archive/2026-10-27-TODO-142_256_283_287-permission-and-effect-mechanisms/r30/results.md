## 意図した差

- 旧 Scope の host/endpoint 検査は IP/CIDR を受け付け、保存したパターンを正規化する。新四入口でも既知の不良を静的に報告する。
- IPv4 射影の IPv6 は、対象の検査では拒否する。パターンと数値の代数の領域は保つ。OS の変換後の相手と型の対象が同じだとは保証しない。
- `Show[ScopeError]` を Trait の側へ移し、Trait が Scope を import する。公開名・Show の出力は保つが、Trait を直接または標準モジュール経由で読む費用が変わる。
- 宣言情報と意味ハッシュの版は4で、型と効果の添字・署名の範囲変数を保持する。旧 manifest/receipt を新版の承認に読み替えない。生成器の本文の規則の版は維持する。
- 七 IO を加えたため、File.Read は13操作、File.Write は16操作、Http.Connect は send/sendIn の2操作を全て処理して完全ハンドラとなる。旧 send だけの節は部分ハンドラである。
- sendIn は3xxに追従せず proxy へ自動接続しない。観測はプログラムが接続する保持 endpoint であり、DNS と TLS の OS の副次的な通信は含めない。参照実行器には登録があるが、HTTP の実通信の本体は VM の runtime を要し参照実行器では実行しない。

性能の記録は本書と tools/bench/results に置き、CHANGELOG やリリースの文書へ増減を写さない。
