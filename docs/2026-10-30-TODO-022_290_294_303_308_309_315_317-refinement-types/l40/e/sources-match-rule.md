# 照合の腕に欄の等号を足す規則の出典

取りまとめが 2026-11-04 に確かめた。2026-11-04 の設計者の決定（plan.md の「## 計画の変更と取りまとめへの確認点」の最初の項目）の規則1について、01-12 の「理由:」に添える他の言語の出典である。

## 確かめた資料

- Ranjit Jhala, Niki Vazou. *Refinement Types: A Tutorial*. arXiv:2010.07763v1, 2020-10-15. <https://arxiv.org/abs/2010.07763>。PDF を取得して本文を読んだ。

## 要点

- 第7章「Data Types」、7.3.3「Checking」、図7.5 の規則 Chk-Alt と、図7.6 のメタ関数 `unapply`・`ctor`。
- Chk-Alt は、照合の対象 `y` が構成子のパターン `D(z)` に合う腕を、`unapply(Γ, y, z, s)` で広げた環境で検査する。`s` は、その照合の場面で具体化した構成子 `D` の型である（`ctor`）。
- `unapply` は、束縛 `z` に構成子の引数の型を与える。そのうえで、構成子の結果の型を照合の対象 `y` の型へ `meet` で結ぶ。本文はこれを、照合で明らかになる対象 `y` の追加の篩（"additional refinements for the scrutinee 𝑦 that are revealed by matching"）と説明する。
- 例（7.3.2 の insert）では、構成子の結果の型に measure の等式（`len(ν) = 1 + len(tl)` の形）があり、腕の中で対象と束縛の長さが結ばれる。

## この改造の規則との対応

この改造の規則は、腕の文脈に「束縛＝照合した値の欄」（整数の sort の欄の値、List の sort の欄の長さ）の事実を加える。チュートリアルの方式は、構成子の型の結果の篩（measure）を対象の型へ結ぶ。どちらも、照合した腕の中で対象と束縛の関係を事実として使えるようにする点で同じ役割を持つ。違いは、関係を表す形が欄の射影の項か measure かである。
