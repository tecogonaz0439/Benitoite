## 導けない条件

S04 は旧 LocalScope・LocalInvariant の Frame/Cont/Cell/State の局所参照の条件を新しい Capture へ拡張し、S10 と .112 は全不変条件を接続する。このとき、捕捉の全 `some` の位置に残る閉包の専用参照も検査する形は、現行の StateTyE から導けない。以下はその全位置の条件が必要とする、一段の検査である。LocalRefs 全体の新しい採用定義ではない。

```lean
SlotBuilderLive (μ : Store) (cap : Capture) : Prop :=
  ∀ ov ∈ cap.values, ∀ runtime body kind op l args,
    ov = some (.closure runtime body) →
    body.code = .builderOp kind op (.loc l) args →
    ∃ c, μ l = some (.builder c)
```

未証明の正の言明は、元状態の StateTyE だけから、この必要条件を含む全位置の局所参照の条件を返すことである。正の言明を定理として宣言していない。以下の反例と空の捕捉の受理例は [HiddenCaptureBoundary.lean](../../../../formal/Benitoite/Release/Refinement/HiddenCaptureBoundary.lean) に置き、既定 import へ含めた。

| 要素 | 実際の値と証拠 |
|---|---|
| ストア | `Store.empty`。場所7は存在しない |
| 内側の閉包の本体 | `Closure.pure (.builderOp .string .copy (.loc 7) [])` |
| 保存する値 | 上の本体と `Tel.done Unit empty` を持つ `Val.closure`。Ground と Adequate は成り立つが、この値を通常値として型付けしていない |
| 外側の捕捉 | `Capture.empty.extend hiddenValue`。元の Γ は `[none]` |
| 外側の本体と継続 | `return Unit`、空の継続 |
| CaptureOk の供給 | `CaptureOk.empty.extendHidden hiddenValue hiddenGround`。None の位置に通常値の型付けを要求しない |
| 元状態 | 任意の P・B・σ について `StateTyE P B σ empty hiddenState` を証明。プログラムと表の条件を除いたことに依存しないので、それらを満たす P・B にも同じ構成を適用できる |
| 成り立たない条件 | 上記の SlotBuilderLive。場所7の builder セルが存在するという結論は偽 |
| 受理側 | 同じ `return Unit` と空の捕捉・空のストアでは、StateTyE と SlotBuilderLive の双方を証明 |

この例は、型付きの実行が存在しない場所の操作へ進むことを示していない。None の位置は外側の本体から読まれず、この状態が表層のプログラムから到達可能であることも証明していない。実行の保存、篩、kind、行の支持、外部応答の不一致の反例ではない。現在の前提が保持する情報と、全位置を対象とする補助不変条件との差である。

## 無断で加えていない変更

CaptureOk・ClosureTy・StateTyE・ValueMeaning と型付けの規則を変更していない。捕捉の全位置の参照の有効性を独立の信頼条件に追加していない。実際の行先本体の型付けを葉の入力に加えていない。型付きのコードとその実際の CaptureLocals だけについて閉じた構築器の三つの状態の葉を、この全位置の条件の証明と数えていない。
