## 更新案の根拠

**L10 は22〜48時間、L20 は39〜90時間、L40 は18〜42時間を維持し、記録から読める能動時間の上限を添える案を推す（読み方(ii)）。** 区間の中では能動時間Aは外側の時間E以下である。計画は能動時間と待ちを分離できない場合に旧見込みを保つと定めるため、今回の上限を自動的に減額へ使わない。二度の停止から生じた後続義務を各段の内数へ明記し、状態一般化と未確認群の旧見込み・余裕を残す。

根拠は、[補題・後続義務の統合表](../l00a.16a/lemmas.md)、[通常記録の時間集計](../l00a.16a/times.md)、[plan「本番の実績を使う外挿と相談条件」](../plan.md#本番の実績を使う外挿と相談条件)、[plan「計画の変更と取りまとめへの確認点」](../plan.md#計画の変更と取りまとめへの確認点)である。二度の停止は未解決のまま後送したものではなく、.12 の最終記録と [RV-L00a.12](../reviews/RV-L00a.12.md)で最小構文の相互置換・narrowing・None入口の完成を確認している。

## 中心の補題の群と算式

記号は次の意味で使う。時間の上限と、まだ分離できない正確な能動時間を区別する。

| 記号 | 意味 |
|---|---|
| E、E_g | 通常の結果記録にある外側の時間。gは作業の群を表す |
| A、A_g | 同じ区間の担当の能動時間。区間内では0 ≤ A ≤ E。正確な内訳は未取得 |
| W、W_g | 同じ区間の待ち時間。分離できる場合はA=E−W |
| p_g | その群に配分した事前の能動時間の計画値 |
| r_g | A_g/p_gという実績比。A未取得でもE_g/p_gを区間内の比の上限として示せる |
| C_sg | 段sに残る、群gの中心補題と同種の証明作業の旧見込み。群別の数値配分はまだない |
| F_s、U_s、T_s | 段sの追随、未確認群/余裕、段全体の旧見込み |
| n_g、N_g、c_g | 同種の本番追随の完了件数、未処理件数、一件当たりの能動時間A_g/n_g。今回はc_g未取得 |
