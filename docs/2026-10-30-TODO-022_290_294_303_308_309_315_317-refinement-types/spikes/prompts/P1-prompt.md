# P1: 値に依存する篩型の Lean の骨格を三案で比べる捨てる試作

`spikes/prompts/P-common.md` の共通条件に従う。書き込み先は `spikes/P1/`。上限は 6 時間（最初の1時間で progress.md）。

## 目的
調べの第7節（Lean の骨格）と第9節の P1 の行。本番の Lean の骨格（Q07 の推す案 `refined(carrier, predicate)` と依存する引数の列）を決め、Release 75・Surface 20 の定理の組み直しの見込みを狭める。

## やること
1. 現行の `formal/Benitoite/Release/Types.lean`（`Ty`・`EffR`・範囲添字 `Ty.opaque o ix`）・`Typing.lean`（`Ty.Le`、V_Sub/C_Sub）・置換の補題を読み、三つの骨格（専用の構成子、`refined(carrier, predicate)`、既存の構成子に篩の添字）を、値に依存する篩（依存する二引数、`List` の長さ、レコードの欄、`Reference`、`Fail`、閉包とハンドラの節）を表せる形で小さく写す。
2. 推す案（`refined` と依存する引数の列）を中心に、移動（shift）と、型・行・範囲・値の四種の置換、F3 の部分型（引数は反変・結果は共変・潜在効果は一原子の被覆）、変性（`List` などの共変、`Reference` などの不変）、依存する β 簡約の型の保存を証明する。ほかの二案は、どこで破れるか・何が増えるかを比べる程度でよい。
3. 調べ 7.2 の既存の抽象化（幅付きの整数・`Byte`・`Decimal` の値域を `V_Const` が要求しない、`Const.opaque` の Top の枝）を、篩の不変条件を使う形に改めるときの最小の変更を一つ示す。
4. 主な定理（進行と保存・`step_sound`・エフェクトの健全性）の言明と前提の中身のどこが変わるかを、写した範囲で具体的に列挙する。`eq_of_not_fn` 系の逆転の補題の置き換え方を一つ以上の例で示す。
5. 本番で直す定理の数と種類の見込みを、写した範囲の実績から更新する。

判定の手続き（線形整数の証明書）は P2 が扱うので、ここでは篩の含意を抽象の判定（仮定として渡す関数とその健全性）で表してよい。その仮定は公理にせず、定理の引数に取る。
