# P3b: 構文の部分型導出の置換と V_Sub の代表

P1 の骨格で、型・行・範囲・値の四名前空間を一般のまま保ち、構文の `TyLe`・`TelLe`・`FieldsLe` の導出の置換と移動、`Eff.Covers` の置換と移動、構文の List と関数の逆転、`V_Sub` の置換の代表を閉じた。型・行の像が外側の値に依存する例も閉じた。最終の Lean 検査は終了0、3.82秒、Python による補助の最大常駐量は830,816,256バイトである。独自の公理・`sorry`・`admit` は各0である。本番の Nat の添字・全ソート・`WF`・全ての型付けの置換は、この試作の対象に含めていない。

成果物は [P3b-Derivations.lean](P3b-Derivations.lean)、最終の検査記録は [P3b-checks-023-final.json](P3b-checks-023-final.json) と [ログ](P3b-checks-023-final.log)、集計は [P3b-checks-summary.json](P3b-checks-summary.json) である。作業は2026-10-30 07:07:43 UTCに開始し、最初の証明と検査は07:27:14 UTCまでの19分32秒で終えた。その後に移動の具体的な文脈写しと heartbeat 上限の比較を追加し、報告の更新を含め23分20秒で終えた。担当の目標2時間より短かったが、本番の変更の較正に使える実測ではない。

元の定義は `P1/Skeleton.lean:1-554` から独立に複写した。namespace だけを `P3b` に改め、`Value`・`Expr`・`Pred`・`Range`・`Ix`・相互再帰の `Ty`/`Eff`/`Tel`/`Fields`・`Sub` と、移動・所属・評価の交換の補題・一原子ごとの `Eff.Covers` を残した。部分型の構成子は元の559-591行を、関数の逆転は1281-1338行を Γ;Φ に一般化した。一原子を分割して覆う案を断る反例は元の808-820行から写した。本番の `.olean` は import していない。

Γ と Φ は、どちらも `Interp T E R → (V → Value) → Prop` とした。Γ は変数の型付け環境の充足、Φ は論理の仮定を表す。P1 の `η` を一つに固定したままでは、型・行の像が値に依存する例を一般には置換できない。この試作では、置換後の各 `η,ρ` に対して元の解釈を `θ.pull w η ρ` とし、Γ・Φ もその解釈で確認する。`TyLe`・`TelLe` の結論と、その置換の帰納の対象は構文の導出である。Γ・Φ が意味上の述語であることと、意味上の部分型だけを示すことを区別する。

置換の `Sub.Valid` が要求するのは、値像の評価と、元の Γ・Φ の保存である。型・行の像の解釈を全ての値環境で一つの `η` に一致させる条件は置いていない。`valid_of_typed` は Γ の保存を型付き置換から証明し、`OpenExample.θ_valid` は残る Φ の保存まで証明する。`context_inhabited` は例の Γ;Φ を満たす環境を一つ構成するため、この例の成功は充足不能な文脈によるものでもない。

| 一原子の範囲 `[1,2]` を、外側の `[1]` と `[2]` に分割して覆える | `cannot_split_one_atom` が否定を証明 | 一つの内側の原子には、それ全体を覆う一つの外側の原子を要する |

| 値に依存する型・行の像を、一つに固定した元の `η` で扱える | 0と1で異なる `pull` の解釈を上記二定理で構成 | 元の解釈を値環境ごとに取る。この試作は Γ・Φ を一般化して扱った |

S1 と S2 の代表の成功条件は、この境界の中で全て閉じた。強い未証明の side condition として型・行の導出の保存を追加していない。`TyLe.sound` は型付き置換の評価から Γ の保存を示すために別途証明したものであり、一般の `TyLe.bind` や List の逆転を意味上の包含へ置き換えるためには使っていない。

最終のソースの SHA-256 は `a74b62fb3bafc6611bb6052e4bd9a786cfd2545f9f59df4b01893f0535d5ca68` であり、検査023の入力と一致する。`#print axioms` を25宣言に対して実行し、現れたのは `propext`・`Quot.sound`・`Classical.choice` だけであった。全ての検査で `lake env lean -M 12288`、1回600秒の上限を使った。タイムアウトはない。

本番の見込み（実測ではない）は、調べの第10.1節の「型の骨格・既存の主定理の接続の基礎」Lean64〜128時間、「値依存の束縛・置換・閉じた状態」Lean80〜200時間、「Scope の統合・TODO-308・F3」Lean32〜80時間を今回の速さだけでは引き下げない。今回の19分32秒は、小さい既存の骨格を複写して S1 と S2 の代表を追加した所要であり、本番の Nat/WF・正規化・全型付け・主定理・Rust との比較の変更を測っていないためである。

この試作によって、第10.1節の値依存の置換の不確かさのうち「構文の導出を置換できるか」と「値に依存する型・行の像を除かずに扱えるか」は、採った表現の範囲で解消した。本番の計画では、一般の置換・束縛下の持ち上げ・被覆の証人の保存・List/F3 の逆転・Γ;Φ の保存・`V_Sub` の枝を、具体的な完了条件として記せる。残る不確かさは、本番の Nat/WF と正規化の等号、および全ての文脈変更への接続である。これらを最初の本番の一群で測り、係数と余裕を再較正する。S2 で列挙した文脈変更に対し、既存の `hle` をそのまま使い回す見込みには戻さない。
