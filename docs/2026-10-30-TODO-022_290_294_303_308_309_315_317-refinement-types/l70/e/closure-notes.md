# 完了判定の根拠の区別

## 検査器の範囲

ソース・宣言・論理の証明書から型・効果と有限の案内を生成し、規則を指定するその案内を再検査する。入力は規則の木・中間の型と効果を持たない。健全性は全ソース・全案内・全成功結果について量化する。宣言の一覧の完全性、型・効果の有限支持、既存の sat・admits の判定との対応は、型付けとは別の入力条件である。案内に型付け又は含意の証明を保持しない。

型付けの単独の例で全場合の完了を推測しない。規則の全構成子は台本の一覧で数え、全入力の健全性の定理と照合する。各補助の正常な前提の実在性は具体の適用で確かめる。

## 四分類

| 対象 | 分類 | 根拠 |
|---|---|---|
| 空篩の初期領域の健全性 | 空疎 | 同じ型の Inhabits に正常な値が存在しないことを証明する。空のパターン列に対して `exhaustive` を返す計算自体は実行できる |
| Month の初期領域 | 実質 | 正常な整数の所属の証人、網羅する範囲と不足する範囲の対照がある |
| 非空 List の初期領域 | 実質 | 非空の値の所属の証人、cons の網羅と空パターン列の対照がある |
| 閉じた長さの初期領域 | 実質 | 任意の Int の長さを量化した定理と、小さい正常値の証人がある。大きい列を評価しない |
| unknown の腕を保持する関数の分岐 | 自明 | unknown のとき入力の腕をそのまま返す定義である |
| unknown に到達する経路 | 実質 | 予算0の判定が unknown を返し、同じ入力の腕の保持へ適用する |
| 将来の構成子を加える view | 実質 | 任意の拡張先を量化し、既存の構成子と追加された構成子の正常値を持つ適用がある |
| 空の構成子表における一覧の完全性 | 自明 | lookup の成功がなく、一覧から外れた構成子が存在しない |

自動燃料を使う高位入口 `unknown_keeps_arms` の前提の実在性は保留である。小さい再帰 data の五つの行列では燃料切れにならなかった（試行入力1297 bytes、SHA-256 `3f6191a639c11dccf9468ed5d9745e0fe6470ca0671824eef6c9443d2ef958cf`、出力64 bytes、SHA-256 `1268d8bd0c54375409b0e6d291d1dfe1b00f69731bf7ab016cfe3877b37b6f29`）。この高位入口の unknown が実在するとは主張しない。全入力の保守性の含意は証明済みであり、明示燃料の低位入口には正常な unknown の証人がある。

| 対象 | 分類 | 根拠 |
|---|---|---|
| 型推論と式・ブロックの実入口 | 実質 | `CheckInferExamples` のunit/let・if/match・呼出し・handlerは案内を渡さず受理し、対応する不正を拒否する |
| 篩の導入と健全性 | 実質 | `refined_result_typed` は同じ型と正の整数の入力について `checkDef_sound` を使い、篩付きの本体を導く。篩の導入・部分型と不正の拒否も実入口で対照を持つ |
| 宣言・実装の型付けと実名 | 実質 | `CheckDeclarationExamples` の関数と全メソッドの実本体、辞書と契約名を照合し、健全性へ適用する |
| 全プログラムと必須の判定の受理 | 実質 | 非空の規則と同じ本体についてdataの契約を受理、otherを型検査後に拒否し、`WellTyped`と受理の範囲の性質へ接続する |
| 証明の会計の打ち切りと不正の拒否 | 実質 | 同じ入力の上限10と1、入れ子、候補選択、実malformedの対照を持つ。各入口のunknownの停止由来の言明にも具体読者がある |
| 初期領域を読む照合の報告と保持 | 実質 | Month・非空List・閉じた長さについて、網羅/不足・領域外候補・被覆の説明・保持の対照と同じ報告への健全性の適用がある |

旧checkerの全ASTの成功保存は不成立であり、Rustが正常に書き出す適格な入力についての一般の成功保存は未証明である。既存コーパスを新しい七入口へかけるF-REGをこの範囲の受け口とする。自動燃料の網羅性のunknownの実在と、全95規則の個別の正常例を、全入力の健全性の証明と混同しない。
