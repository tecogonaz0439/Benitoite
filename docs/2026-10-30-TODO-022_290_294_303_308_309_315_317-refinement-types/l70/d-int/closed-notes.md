## 閉じた範囲の変更

`CheckArguments.head` はソースの `RangeIx` 列を `closedRanges` で読む。関数の頭では `rangesFit` が種類・WF・Canonical を検査し、`functionRangeTel` は空の具体化で元の依存列を保ち、非空で範囲を具体化する。型・効果の具体化はその後に行う。組込みの頭も `RangeExpr` の全構成子を閉じた範囲として扱う。`CheckSource` と、出現を数える `Identity`・局所解析の `ScopeLower` は増えた範囲欄を保って構文を走査する。

範囲の具体化で効果の原子が変わるため、有限支持の一覧には実際に渡す範囲の写像の像も含める。これは構文の支持の条件であり、型付けや許容の信頼を仮定する欄ではない。空の範囲列での写像は恒等で、`rangeSupport_nil` と `function_empty_support` が元の型・行の支持だけの形を返す。

`ScopeAccept` は未具体化の範囲も全出現の走査に保持する。閉じた絶対範囲以外の契約に必須の規則が選ばれた場合は、具体の被覆を示せないため `unknownSource` を返す。契約の範囲変数を Top と読み替えて受理しない。選ばれた規則がない場合は既存の規則なしの扱いを保つ。`acceptBody_ranges` は成功した全出現について、規則が選ぶ各位置に固定した絶対範囲の契約とその被覆の証人を返す。その契約はどの具体化でも変わらない。元の四つの `acceptBody_sound`・`some`・両 unrecorded は、`List Range` を `RangeIx.fixed ∘ RangeExpr.absolute` で埋め込んだ同じ結論の系として保つ。`CheckAcceptedRanges.BodyRanges` は全 `List RangeIx` 出現を量化する。

## 開いた引数の接続

`CheckBuiltinSource` は任意の表・標準表の宣言データ・範囲許容を常に真として構成する表の三つを区別する。`unrestrictedRanges B` の実際の表は `{ B with admitsR := fun _ _ => True }` であり、B の元の範囲許容が全具体化で保存されるという仮定ではない。標準表の意味を上書きせず、選択したデータから checker が読む表を一意に構成する。host の実入口例は、既存の例と署名・値の種類を共有し、範囲許容を真と明示した新しい小表として親担当が構成する。既存の例の表は組込み名と範囲列の長さも照合するため、新しい小表との全域の同一性は主張しない。有効な署名は inspect 一つで、その範囲の個数は `RangeAdmissible` が1と要求するため、有効な呼出しに限った許容は同じである。既存の表をそのまま実入口へ写したとは記録しない。

`CheckOpenAdmissible` は型・行引数を `q.rangeKinds.length` の深さで一度検査し、`OpenLeafFormation` の形成の構造体を返す。Q と行の計算は既存の関数を再利用する。`CheckOpenArgumentLeaves` は、標準表では `RangeStandard` の保存補題を使い、任意の表では型引数の範囲閉性を有限に検査する。制約・型引数の許容・関数の許容・範囲引数の許容を、それぞれ全具体化の葉へ導く。標準の範囲の許容では、呼出し名と種類・構文上の被覆を検査する。

`CheckOpenRangeSupport` は、実際の開いた範囲引数ごとに、原子の有限一覧が写像の像を含むかを検査する。型・依存列・型の列・効果は構造的に写像し、効果の原子は一覧を走査して像を作る。有限支持の前提から、計算した写像が `Ty.rawMapRanges`・`Tel.rawMapRanges`・`Eff.rawMapRanges` と等しいことを示す。これにより、無限の存在で定義された非計算的な `rawMapRanges` を検査器の計算に使わず、有限な計算と本番の開いた型を接続する。`openRangeTel_checked` はその等号と結果の支持を返す。

`CheckOpenArguments` は既存の辞書・案内・値の支持の型を再利用する。辞書、実引数の値、列、依存列、関数・組込み・操作・メソッド・外部の頭を、開いた表層の各判断へ写す。頭の範囲の写像の支持は、入力への新しい意味上の仮定ではなく、実際に計算した `rangeSupport` の成功から得る。`HeadInputsSupport` が未具体化の範囲で空疎になっても、それを開いた依存列の支持として流用しない。
