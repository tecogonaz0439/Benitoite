# 設計書

関数型スクリプト言語 Benitoite（ベニトアイト）の設計書である。CLI のコマンドの名前は `benitoite`、スクリプトの拡張子は `.bnt` とする。処理系は Rust で実装する。

本設計書は、初回リリース版（`0.0.1`）の処理系が実装した内容だけを書く。まだ実装していない機能、未解決の問い、確かめていない事実は、docs/todo の項目（`TODO-nnn`）にする。docs/todo は、設計者が手元に持つ非公開の別のリポジトリであり、公開のリポジトリには含めない。

## 構成と読み方

- `01-spec/` は言語仕様である。何が正しいプログラムで、それがどう動くかだけを定め、言語処理系（以下、処理系）の実装方式には依存しない。
- `02-impl/` は処理系の設計である。`01-spec/` の定めをどう実装するかを扱う。
- 本文には現在の決定を書き、判断の理由を決定の直後に「理由: 〜。」として短く添える。検討した代替案と却下した理由は、改造ごとのディレクトリ（`docs/YYYY-MM-DD-TODO-nnn_nnn_…-<改造の名前>/`。名前の決まりは AGENTS.md の「改造の進め方」）に書き、改造を終えたら `docs/archive/` に保管する。
- 初回リリース版で加えた節は、見出しに「（初回リリース版）」と記す。処理系のコメント、テスト、道具がこの見出しを名前で参照している。
- 章の番号は詰めない。初回リリース版に含めない機能を扱っていた章（02-12、04 の部、05-02・05-03、06-02・06-05・06-07・06-08）の番号は欠番である。

## 凡例

- 【決定】合意済み
- 【方針】暫定の既定路線
