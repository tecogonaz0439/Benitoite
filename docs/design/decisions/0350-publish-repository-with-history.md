# 0350. リポジトリを履歴ごと公開し、設計メモとコミットのメールアドレスも公開する

- 状態: 採択（決定 1 の履歴ごとの公開を [0358](0358-release-versions-and-published-history.md) で改め、公開するブランチを `san_benito` だけとし、公開する履歴を集約した。帰結の、コミットの番号が公開の後も有効であることは成り立たなくなった）
- 日付: 2026-10-08
- 関連章: [配布形態](../05-platform/05-01-distribution.md)
- 関連する未決事項: [OPEN-061](../open-issues.md#open-061)

## 背景

このリポジトリは、初回リリース版をリリースするときに GitHub で公開する（[ADR 0233](0233-distribution-via-github-releases.md)）。公開の前に、設計メモ（`docs/design/sources/fp-language-design.md`）の扱いを決めることにしていた（[OPEN-061](../open-issues.md#open-061)）。

公開の前のセキュリティのレビューで、リポジトリの中身と git の履歴を点検した。秘密の情報（API キー・トークン・秘密鍵）は、どの参照からも辿れない対象を含めて、履歴のどこにもなかった。履歴にだけ残る個人の情報は、すべてのコミットの著者とコミッタのメールアドレスだけだった。設計メモは最初のコミットから履歴にあり、公開の対象から外すには履歴の書き換えが要る。

## 決定

1. リポジトリを、履歴ごと公開する。
2. 設計メモを公開の対象に含める。OPEN-061 は、この案で決着とする。
3. コミットの著者とコミッタのメールアドレスを、そのまま公開する。

## 検討した代替案

- **まっさらな履歴で公開する**: メールアドレスと設計メモの扱いを公開の時点で自由に選べ、クローンも小さくなる。しかし、LLM が設計と実装を進めた経緯（ADR とコミットの対応、`git blame`）が失われ、設計書と測定の記録が参照するコミットの番号（約 40 件）が辿れなくなる。
- **履歴を書き換えて、メールアドレスを差し替える、または設計メモを除く**: 経緯は残るが、コミットの番号はすべて変わるので、文書の中の番号が辿れなくなる点はまっさらな履歴と同じである。

## 帰結

- 履歴を書き換えないので、設計書と測定の記録が参照するコミットの番号は、公開の後も有効である。
- 公開するのは作業のブランチ（`san_benito`）の履歴とする。押し潰す前の履歴の写し（`backup/*`、`san_benito-before-squash`）は公開しない。測定の記録が参照する、作業のブランチの外のリビジョンを出すかは、公開の手順で決める。
- 設計書の最終版で設計メモへのリンクを外す方針（AGENTS.md の「参照資料の保存」）は変えない。
