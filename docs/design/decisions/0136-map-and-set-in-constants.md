# 0136. Map と Set のリテラルは設けず、定数式に `Map.fromList` などを書けるようにし、重なる鍵を報告する

- 状態: 採択
- 日付: 2026-09-28
- 関連章: [構文](../01-spec/01-02-syntax.md), [評価意味論](../01-spec/01-08-evaluation.md), [標準ライブラリ](../03-interop/03-06-stdlib.md), [診断エンジン](../02-impl/02-10-diagnostics.md), [他の言語の調査記録](../08-appendix/08-03-language-surveys.md)
- 関連する未決事項: [OPEN-012](../open-issues.md#open-012)

## 背景

`Map` と `Set` には、リテラルの構文を設けず、`Map.fromList` と `Pair` で作ると決めた（[ADR 0103](0103-map-and-set-ordered-by-key.md) の決定 6）。同じ鍵の組が重なると、後の組の値を使う（[標準ライブラリ](../03-interop/03-06-stdlib.md)）。

トップレベルの定数の定数式には、関数の呼び出しを書けない（[ADR 0123](0123-top-level-constants.md)）。このため、変換の表のような `Map` と `Set` を定数にできず、引数のない関数で返すしかない。

他の言語の調べた結果は[他の言語の調査記録](../08-appendix/08-03-language-surveys.md)の「Map と Set の値の書き方」に記録した。要点は次のとおりである。

- Haskell・Elm・OCaml・F#・Gleam・Roc・Rust・Scala・Kotlin は、マップのリテラルを持たず、`fromList` の形の関数で作る。Kotlin は、実験中のコレクションのリテラルから、マップを明示で外した。
- Python・Dart・Swift・Elixir・Clojure・Go は、マップのリテラルを持つ。
- マップを定数にできるのは Dart の `const` だけである。Gleam・Kotlin・Go は、マップを定数にできない。
- 同じ鍵を重ねて書いたとき、Dart の定数のマップ、Go の定数の鍵、Clojure のリテラルは静的な誤りとする。Elixir・Ruby・Dart の定数でないマップは、警告を出して後の値を使う。

## 決定

1. `Map` と `Set` のリテラルの構文は、これまでどおり設けない（ADR 0103 の決定 6 は変わらない）。
2. 定数式に、`Map.fromList(e)`・`Set.fromList(e)`・`Map.empty()`・`Set.empty()` を書ける。引数 `e` は定数式でなければならない。ほかの関数の呼び出しは、これまでどおり定数式に書けない。
3. 定数式の `Map.fromList` の引数に同じ鍵の組が二つ以上あるとき、また `Set.fromList` の引数に同じ要素が二つ以上あるときは、検査の誤りとする。同じかどうかは鍵の型の等しさ（鍵の順序で等しいこと）で判定する。`1.0m` と `1.00m` は同じ鍵である。
4. 定数式の外で、`Map.fromList` の引数がリストのリテラルであり、その中の組の鍵が定数式で同じ値になるものが二つ以上あるときは、警告とする。`Set.fromList` の要素も同じである。警告は検査と実行を止めず、意味はこれまでどおり後の組の値を使う。

## 検討した代替案

- **Swift と同じリテラル `["a": 1]`（空は `[:]`）を設ける**: 書く量は減る。しかし、`Pair` と `Map.fromList` で書けるものに二つ目の書き方を加える（原則 5）。集合は型の注釈がなければリストと見分けられず、構文の規則も増える。波括弧は ADR 0108 で禁じているので、Python や Dart の書き方は選べない。
- **定数にはできないままにする**: 定数式の規則は変わらない。しかし、表のような値を関数で返すことになり、値が実行の前に定まることを型で示せない。
- **定数の中でも、重なる鍵は後の値を使う**: 定数の外と意味が揃う。しかし、定数式は実行の前に計算するので、重なりを静的に報告できる。重なる鍵は書き誤りである見込みが大きい（原則 1）。

## 帰結

- `const statusNames: Map[Integer, String] = Map.fromList([Pair(200, "OK"), Pair(404, "Not Found")])` のように、表を定数にできる。
- ADR 0123 の定数式の範囲に、決定 2 の四つの関数の呼び出しを加える。
- 定数の中と外で、重なる鍵の扱い（誤りと警告）が異なる。値の意味（後の値を使う）は、定数の外では変わらない。
- 警告の診断コードは[診断エンジン](../02-impl/02-10-diagnostics.md)の区分 `W` で定める。
