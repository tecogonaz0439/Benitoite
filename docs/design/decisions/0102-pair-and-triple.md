# 0102. 組の型を `Pair` と `Triple` に限り、括弧のタプルは設けない

- 状態: 採択
- 日付: 2026-09-28
- 関連章: [代数的データ型とパターンマッチ](../01-spec/01-05-data-types.md), [構文](../01-spec/01-02-syntax.md), [名前・スコープ・モジュール](../01-spec/01-03-names-modules.md), [標準ライブラリ](../03-interop/03-06-stdlib.md)
- 関連する未決事項: [OPEN-012](../open-issues.md#open-012)

## 背景

最小実行版には、名前を付けずに値を組にする型（タプル）がなかった。関数から複数の値を返すときと、マップの鍵と値の組を表すときに要る。

タプルの要素の個数の上限は言語によって違う。Elm は 3 要素まで、Kotlin は汎用のタプルを持たず `Pair` と `Triple` だけを持ち、それより多い組はデータクラスで書かせる。Scala 2・Haskell・Rust は、型クラスやトレイトの実装を要素の個数ごとに書く必要があるので、実装を持つ個数に上限がある。これらの言語の扱いは、一次資料で確かめていない。

上限の有無は、インタプリタの性能にはほとんど影響しない。組の値は、構成子が一つの代数的データ型と同じ形で表せ、作る・比べる・照合する手間は要素の数に比例するだけだからである。

## 決定

1. prelude に、組の型 `Pair[A, B]` と `Triple[A, B, C]` を設ける。構成子が一つだけの代数的データ型であり、構成子の名前は型の名前と同じである。4 要素以上の組は、利用者が `record` を宣言して書く。
2. 組は `Pair(1, "one")` の形で作る。要素は `Pair.first`・`Pair.second`、`Triple.first`・`Triple.second`・`Triple.third` で取り出す。
3. `switch` の分岐のパターン（`case Pair(0, name):`）と、`let` の左辺（`let Pair(n, name) = p`）で分解できる。
4. 構成子が一つだけで、その名前が型の名前と同じ型は、構成子を型の名前で修飾せずに書く（`Pair.Pair(…)` ではなく `Pair(…)`）。利用者が宣言した同じ形の型にも当てはめる。
5. `let` の左辺には、必ず照合するパターン（照合に失敗しないパターン）を書ける。照合に失敗しうるパターン（`Option.Some(x)` など）は型検査の誤りとし、`switch` を使うよう示す。
6. 括弧のタプル（`(1, "one")`、型の `(Integer, String)`、パターンの `(a, b)`）は構文エラーとし、`Pair`・`Triple`（4 要素以上は `record`）を修正案として示す。
7. 要素の型がすべて等値の型なら、`Pair` と `Triple` も等値の型である。

## 検討した代替案

- **括弧のタプル `(A, B)` を設け、要素の個数に上限を設ける**: 多くの関数型言語と同じ形である。しかし、要素に名前のない組が長くなると取り違えやすく、`Pair`・`Triple` の方が語として意味を読み取れる。
- **4 要素以上にも名前を付ける（`Quadruple`・`Quartet` など）**: 語はあるが、見慣れない語で綴りと個数を取り違えやすく、欄の名前（`fourth` など）にも意味がない。
- **`Pair` と `Triple` を prelude のレコードにする**: 既存のレコードの規則で扱える。しかし、レコードは作るときもパターンでも欄の名前を書くので、`Pair(first: 1, second: "one")` となり、Kotlin の `Pair(1, "one")` の形にならない。
- **`let` の左辺のパターンを `Pair` と `Triple` に限る**: 規則は狭い。しかし、レコードや利用者の構成子が一つの型も同じく必ず照合するので、限る理由がない。必ず照合するかは、網羅性の検査でそのまま判定できる。

## 帰結

- 最小実行版の「`let` の左辺にパターンは書けない」という規則を改める。
- 修飾しない大文字の名前を式とパターンに書ける場合に、「構成子が一つだけで型と同名の型の構成子」を加える。
- マップの鍵と値の組を `Pair` で表す（[ADR 0103](0103-map-and-set-ordered-by-key.md)）。
- 型クラスの実装を組に持たせるときは、`Pair` と `Triple` の二つについて書けばよい。
- 括弧のタプルと `Pair`・`Triple` の LLM の書き誤りの率を、[OPEN-012](../open-issues.md#open-012) の測定の対象に含めるかは【未決】である。
