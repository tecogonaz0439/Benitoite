# 0175. スクリプトを埋め込んだ単一バイナリは、初回リリース版に含めず、正式リリース版の前までに実装する

- 状態: 採択
- 日付: 2026-09-29
- 関連章: [全体像](../00-overview/00-02-architecture.md), [ロードマップ](../00-overview/00-03-roadmap.md), [スクリプト実行と埋め込み](../02-impl/02-11-embedding.md), [配布形態](../05-platform/05-01-distribution.md)
- 関連する未決事項: なし

## 背景

設計メモ 20 は、依存のない単一バイナリを配布できるように言語仕様の策定時から考慮し、実装は後回しにするとした。基準案は、VM とスクリプトを一つの実行ファイルに埋め込む形である（[全体像](../00-overview/00-02-architecture.md)の「配布物」）。ロードマップは、スクリプトを埋め込んだ実行ファイルの生成を初回リリース版に含めず、将来拡張に挙げていたが、実装する時期を決めていなかった。

## 決定

1. スクリプトを埋め込んだ単一バイナリ（処理系の VM とスクリプトを一つの実行ファイルにしたもの）の生成は、初回リリース版に含めない。
2. 初回リリース版の後、正式リリース版（`1.0.0`）の前までに実装する。
3. 初回リリース版の設計は、これを後から加えられるように保つ。実行ごとの状態を実行の入力から作る形（[スクリプト実行と埋め込み](../02-impl/02-11-embedding.md)）と、コンパイル済みプログラムをファイルに保存しない方針（[処理系の全体の流れ](../02-impl/02-01-pipeline.md)）は、この機能を設計するときに見直してよい。

## 検討した代替案

- **初回リリース版に含める**: 利用者に処理系を入れてもらわずにスクリプトを配れる。しかし、埋め込む形（ソースかコンパイル済みプログラムか）、埋め込んだ実行ファイルの権限の与え方、ライセンスの表示（[OPEN-021](../open-issues.md#open-021)）を初回リリース版の前に決める必要があり、実行時の権限制御の方式（[OPEN-052](../open-issues.md#open-052)）が決まる前に決めることになる。
- **時期を決めずに将来拡張に残す**: 正式リリース版の互換性の約束に、埋め込みの形を含めるかを決められない。

## 帰結

- 正式リリース版とする条件（[OPEN-040](../open-issues.md#open-040)）に、この機能の実装を含める。
- 埋め込む形と権限の与え方は、実装する版で[スクリプト実行と埋め込み](../02-impl/02-11-embedding.md)と[配布形態](../05-platform/05-01-distribution.md)に定める。
