# 0245. 三大美徳の英語表記の出典を `perlglossary` で確かめ、先行事例の残りの事実と Khorikov の書籍の確認を正式リリース版の前に行う

- 状態: 採択
- 日付: 2026-09-29
- 関連章: [目的と設計原則](../00-overview/00-01-goals.md), [先行事例索引](../08-appendix/08-02-prior-art.md), [処理系のテスト戦略](../07-quality/07-03-compiler-testing.md)
- 関連する未決事項: [OPEN-013](../open-issues.md#open-013), [OPEN-014](../open-issues.md#open-014), [OPEN-038](../open-issues.md#open-038)

## 背景

設計書には、一次資料で確かめていない外部の事実が三つの未決事項として残っていた。

- 標語の三大美徳の英語表記（Laziness, Impatience, Hubris）が、『Programming Perl』での呼び方と一致するか（[OPEN-013](../open-issues.md#open-013)）。
- 先行事例索引に書いた各言語の成り立ちなどの事実（[OPEN-014](../open-issues.md#open-014)）。最初の対象は、Perl の成り立ち（「1987 年ごろ、業務で報告書を作るために awk を補う道具として作った」）であった。
- テストの設計の原則の要約が、Khorikov の書籍の記述と一致するか（[OPEN-038](../open-issues.md#open-038)）。

初回リリース版を提供する前に決着させるのは、初回リリース版の範囲にかかわる未決事項である（[ADR 0178](0178-resolve-all-open-issues-before-stable-release.md)）。

2026-09-29 に、開発機の Perl 5.34.1 の文書で次のことを確かめた。

- `perlglossary` は、その DESCRIPTION で、『Programming Perl』第 4 版の用語集から作ったと述べている。laziness・impatience・hubris の項は、それぞれをプログラマの第一・第二・第三の大きな美徳（great virtue）と定義している。
- `perlhist` は、Perl 1.000 の公開を 1987-12-18 としている。
- `perl(1)` の DESCRIPTION は、Perl はもともと任意のテキストファイルを走査し、情報を取り出し、その情報に基づいて報告を出力することに最適化した言語であったと述べる。あわせて、作者の意見として、sed・awk・sh の優れた機能を組み合わせたとする。

`perl(1)` と `perlhist` は、「業務で」作ったことと、「awk を補う」道具として作ったことを述べていない。

## 決定

1. 標語の英語表記は、`perlglossary`（『Programming Perl』第 4 版の用語集に基づく）の laziness・impatience・hubris に合わせたものとして確定する。OPEN-013 は決着とする。
2. 先行事例索引の Perl の成り立ちの文は、`perl(1)` と `perlhist` が述べる事実（1.000 の公開が 1987-12-18 であること、テキストの走査と報告の出力に最適化した言語として始まり、sed・awk・sh の機能を組み合わせたこと）に書き改める。「業務で」と「awk を補う」は書かない。
3. OPEN-014 の残り（F#、Racket、Ada などの付録の事実）は、初回リリース版の設計と実装に影響しないので、正式リリース版の前に確かめる。
4. OPEN-038 も、正式リリース版の前に確かめる。原典は、設計者が書籍を用意して確かめることがある。

## 検討した代替案

- **OPEN-014 と OPEN-038 も初回リリース版の前に確かめる**: 設計書の事実の誤りが早く直る。しかし、どちらも初回リリース版の仕様と実装を変えない。ADR 0178 は初回リリース版の前に決着させる範囲を初回リリース版にかかわる事項に限っており、確認の作業を初回リリース版の前に集める理由がない。

## 帰結

- 目的と設計原則と先行事例索引の、標語の出典の【要検証】を外す。
- OPEN-014 と OPEN-038 は、種別を要検証のまま残し、確かめる時期を正式リリース版の前とする。
