# 0093. 言語にない構文と、使う予定の決まっていない構文の語を予約しない

- 状態: 採択（`return` は [0096](0096-explicit-return.md) でキーワードにした）
- 日付: 2026-09-27
- 関連章: [字句構造](../01-spec/01-01-lexical.md), [字句解析器と構文解析器](../02-impl/02-03-frontend.md), [診断エンジン](../02-impl/02-10-diagnostics.md)
- 関連する未決事項: [OPEN-012](../open-issues.md#open-012)

## 背景

最小実行版の設計は、`as`・`break`・`continue`・`for`・`loop`・`return`・`where`・`while` を予約語にしていた。どれも Benitoite では構文上の意味を持たず、初回リリース版で使う予定もない。予約した理由は、LLM が他の言語の制御構文を書いたときに、「この言語にはその構文がない。再帰を使う」のように、誤りの原因を示す診断を出せるようにすることであった。

また、`class`・`instance`・`var`・`mutable`・`module`・`derive` を、将来の構文のために予約していた。`class`・`instance` は型クラスの構文の候補だったが、型クラスは `trait`・`implement` で書くことにした（[ADR 0060](0060-trait-and-impl-syntax.md)、[ADR 0092](0092-unabbreviated-keywords.md)）。`var`・`mutable` は可変の変数、`module` はモジュールの宣言、`derive` は実装の自動の生成の候補であるが、どれも実装するかが決まっていない。

制御構文の語を予約する理由は、LLM がこれらの語を書く頻度と、的を絞った診断によって LLM が誤りを直しやすくなる程度についての見込みである。どちらも測定していない。

## 決定

1. `as`・`break`・`continue`・`for`・`loop`・`return`・`where`・`while` を予約語から外す。これらは識別子として使える。
2. `class`・`instance`・`var`・`mutable`・`module`・`derive` を予約語から外す。これらの語を使う構文を加えると決めたときに、キーワードにする。
3. 利用者が定義するエフェクトとハンドラの構文のために、`handle` と `resume` は予約語に残す。
4. 1 の語を予約語に加えるかどうかは、[OPEN-012](../open-issues.md#open-012) の測定で確かめて決める。測定は初回リリース版の実装プランを作る前に行う。

## 検討した代替案

- **将来の構文の候補の語を予約しておく**: 構文を加えたときに、その語を識別子に使ったスクリプトを壊さずに済む。しかし、初回リリース版の前であれば、予約語を加えてもどのスクリプトも壊さない。初回リリース版の後に構文を加えるときは、互換性を壊す変更として扱う（ほかのキーワードと同じ扱いである）。
- **制御構文の語を予約語のままにする**: LLM が `for` や `return` を書いたときに、繰り返しの代わりに再帰や `List.map` を使うよう示す診断を出せる。しかし、その診断が LLM の修正の成功率を上げるかは測定していない。予約語を識別子として使えないことは、利用者にとって規則が一つ増えることでもある。予約語を外す変更はどのスクリプトも壊さず、初回リリース版の前であれば予約語を加える変更もどのスクリプトも壊さないので、測定の前に予約しておく理由はない。

採った案の弱点は、LLM が `for x in xs { ... }` や `return x` と書いたときに、原因を示す診断ではなく、一般の構文エラーや名前解決の誤り（`return` という名前がない、など）になることである。

## 帰結

- [字句構造](../01-spec/01-01-lexical.md)の予約語の一覧から十四の語を外し、[字句解析器と構文解析器](../02-impl/02-03-frontend.md)の予約語ごとの修正案の表と、[診断エンジン](../02-impl/02-10-diagnostics.md)の修正案を示す診断の表を改める。
- 最小実行版の処理系は、これらの語を予約語として扱ったままであり、設計の段階では直さない。初回リリース版の処理系は、設計書の予約語の一覧に従う。
- 設計書の例を確かめる道具（`tools/grammar-check`）の、予約語の一覧を登録した項目を改める。
