# 0154. 公開する契約の検査に、エフェクトと上位の型クラスを含める

- 状態: 採択
- 日付: 2026-09-29
- 関連章: [名前・スコープ・モジュール](../01-spec/01-03-names-modules.md), [型システム](../01-spec/01-06-type-system.md), [エフェクト](../01-spec/01-07-effects.md)
- 関連する未決事項: なし

## 背景

`public` を付けた関数の引数の型と戻り値の型、`public` を付けた型の構成子の引数の型に、`public` を付けていない同じモジュールの型を使うと誤りとする（[ADR 0053](0053-private-by-default-with-pub.md)）。初回リリース版では、同じ規則を、レコードのフィールドの型、型クラスのメソッドの型、型クラスの制約、定数の型の注釈、型の別名の右辺にも当てはめる（[名前・スコープ・モジュール](../01-spec/01-03-names-modules.md)）。

この列挙には、次のものがない。

- 公開する関数と型クラスのメソッドの `uses` に書くエフェクト。非公開のエフェクト `Secret` を持つ `public function f(): Unit uses Secret` を許すと、取り込んだ側は `Secret` を自分の `uses` に書けず、ハンドラの節にも書けないので、`f` を呼ぶ関数に型を付けられない。
- `public effect` の操作の引数の型と戻り値の型。
- `public trait` の上位の型クラス。

この欠けは、外部の検証者による 01-spec のレビューで指摘された。

## 決定

1. 公開する契約（`public` を付けた関数、`public trait` のメソッド、`public effect` の操作の型）に現れる型・型クラス・エフェクトに、`public` を付けていない同じモジュールのものを使うと誤りとする。関数の型の内側（引数に渡す関数の型など）に現れるものも含む。
2. 1 の対象には、`uses` に書くエフェクト、`public effect` の操作の引数の型と戻り値の型、`public trait` の上位の型クラスを含める。
3. 非公開のエフェクトは、モジュールの中の関数で使い、公開する関数の外へ出る前にハンドラで処理する。

## 検討した代替案

- **非公開のエフェクトを公開する関数の `uses` に書くことを許し、取り込んだ側が名前を書かずに扱う方法を設ける**: エフェクト変数として受け取ることはできるが、名前を書けないので、ハンドラで処理することができない。取り込んだ側は、`main` まで伝えても処理系が行わない操作を持つことになり、プログラムを実行できない。

## 帰結

- 公開する関数の型に現れるものは、すべて取り込んだ側から名前で書ける。
