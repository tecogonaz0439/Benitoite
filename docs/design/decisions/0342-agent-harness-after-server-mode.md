# 0342. エージェントハーネスと TUI をサーバモードより後に作り、承認の画面だけを TUI の部品で先に作る

- 状態: 採択
- 日付: 2026-10-08
- 関連章: [エージェントハーネス](../06-tooling/06-08-agent-harness.md), [サーバモード](../06-tooling/06-07-server.md), [ロードマップ](../00-overview/00-03-roadmap.md)
- 関連 ADR: [0194](0194-tui-and-own-coding-agent-with-server-mode.md), [0188](0188-authentication-by-user-presence.md), [0178](0178-resolve-all-open-issues-before-stable-release.md)
- 関連する未決事項: [OPEN-055](../open-issues.md#open-055), [OPEN-056](../open-issues.md#open-056)

## 背景

[ADR 0194](0194-tui-and-own-coding-agent-with-server-mode.md) は、TUI と自前のコーディングエージェント（利用者の依頼から LLM にスクリプトを書かせ、検査と修正を繰り返す仕組み。以下、エージェントハーネス）を、サーバモードとあわせて作ると決めた（決定 1・2）。決定 1 の TUI は、承認の画面（[ADR 0188](0188-authentication-by-user-presence.md)）、ジョブの状態と出力の表示を含む。

エージェントハーネスは、LLM の API との連携、対話の管理、道具の実行を含み、範囲が大きい。サーバモードとあわせて作ると、サーバモードの提供がその分だけ遅れる（ADR 0194 の帰結）。設計者は、2026-10-04 に、作る時期を改めた（[自前のエージェントハーネスの検討メモ](../sources/post-first-release/post-first-release-agent-harness.md)の「設計者の決定」）。

一方、サーバモードの認証は承認の画面を要する（ADR 0188）。TUI を後に回すと、サーバモードの時点で承認の画面だけを別に用意する必要がある。

## 決定

1. TUI とエージェントハーネスは、サーバモードより後に実装し、正式リリース版の前までに実装する。エージェントが使う口のうちサーバモードとあわせて実装するのは、MCP の中継（`benitoite mcp`）だけとする（承認の画面は決定 2）。ADR 0194 の決定 1・2 のうち、「サーバモードとあわせて作る」という時期を、本決定で改める。
2. 承認の画面（`benitoite server approve`）は、TUI の部品（画面の枠組み）で作り、サーバモードとあわせて実装する。後で作る TUI と、見た目と操作を揃えるためである。TUI の部品には既存の OSS を使う（ADR 0194 の決定 4）ので、その部品をサーバモードの時点で取り込む。
3. エージェントハーネスは、サーバモードがあることを前提にする。サーバモードのない版でエージェントハーネスを動かす経路は作らない。

ADR 0194 の次の決定は変えない。エージェントハーネスがサーバモードを通してスクリプトを検査・実行すること（決定 2 の後半）、LLM を使ったテストに使える形を目指すこと（決定 3）、LLM の API のクライアントと TUI の部品に既存の OSS を使うこと（決定 4）、設計の未決事項を [OPEN-056](../open-issues.md#open-056) で決めること（決定 5）。

## 検討した代替案

- **ADR 0194 のとおり、サーバモードとあわせて作る**: 承認の画面を TUI の一部として一度で作れる。しかし、サーバモードの提供がエージェントハーネスの分だけ遅れる。外部のエージェントは MCP でサーバモードを使えるので、エージェントハーネスがなくてもサーバモードの価値は得られる。
- **承認の画面を、端末の簡単な対話の画面で作る**: 作る量が少ない。しかし、後で TUI ができたときに、作り直すか残すかの判断が要る。

## 帰結

- [サーバモード](../06-tooling/06-07-server.md)の「構成」の表と、[ロードマップ](../00-overview/00-03-roadmap.md)の「将来拡張」の表を、本決定に合わせて直す。エージェントハーネスの設計は、[エージェントハーネス](../06-tooling/06-08-agent-harness.md)の章で定める。
- サーバモードの実装は、TUI の部品の OSS への依存を含む。
- TUI の画面の構成と承認の画面の関係は、[OPEN-056](../open-issues.md#open-056) に残る。
- 正式リリース版の前にすべての未決事項を決着させる（[ADR 0178](0178-resolve-all-open-issues-before-stable-release.md)）ので、エージェントハーネスの未決事項も、その時点までに決着させる。
