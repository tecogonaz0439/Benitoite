- 依存する作業: [R06](R06-values-and-lists.md)、[R07](R07-typed-builtins.md)

- 規模の見込み: 中（500〜1500 行）
- ブランチ: impl/R10-refinterp-values

## 目的

参照インタプリタの値の型を、VM の値・ヒープ・VM から独立した、`Rc` による安全で単純な型として作る（[ADR 0268](../../design/decisions/0268-staged-runtime-rebuild.md) の決定 2、[ADR 0276](../../design/decisions/0276-reference-interpreter-shares-builtin-bodies.md) の決定 1）。VM の値の実装の不具合が参照インタプリタにも同じく現れて、差分テストで見つからないことを避けるためである（02-08「参照インタプリタ」）。

参照インタプリタは、組み込みの関数を呼ぶときだけ、引数を自分の値からヒープの値に変換し、VM と同じ組み込みの関数の本体を呼び、結果を自分の値に戻す（ADR 0276 の決定 2）。本作業は、この値の型と変換と、変換を使って組み込みの関数を呼ぶ手順を作る。評価（01-12 の遷移）は F14 が、本作業の値と変換の上に書く。

## 手順の要点

### 値の型

- 01-12 の値と、ストア σ が持つもの（セル、明示遅延の対象、継続）を表せる列挙型にする。第 1 段の組み込みの関数と F14 の評価が使う種類として、少なくとも次のものを持つ: `Integer`・`Float`・`Byte`・`Boolean`・`Character`・`Unit`、文字列、`Bytes`、構成子を適用した値（タグと引数の並び。引数のない構成子を含む）、リスト、関数の値（F14 が中身を決める閉包）、`IOError`。`Decimal`・マップ・集合・セル・`Lazy`・継続・中身を見せない値・リソースは、F14 と後の作業が加えられるように、加える場所を決めておく（`#[non_exhaustive]` にはしない。lint `wildcard_enum_match_arm` で漏れを見つけるため）。
- 共有する部分構造は `Rc` で持つ。値の型は VM の型（`runtime::heap::Value`・`Slot`・`ObjRef`）を欄に含まない。
- リストは、`Rc` の連結リストか `Rc<[Value]>` など、VM の表現と別の単純な形で持つ。長いリストや深い構造の値を捨てるときに、Rust の既定の `drop` の再帰でスタックを使い果たさないよう、`Drop` を明示の積み重ねで書く（00-02「再帰の深さ」。最小実行版の `src/legacy/runtime/value.rs` の解放の手順が参考になる）。
- 構造の等しさ（`=`）を参照インタプリタの値の上で書く。VM の `runtime::equal` は使わない（値を共有しない方針による）。01-06「等値の型」のとおりにし、明示の積み重ねで辿る。

### 変換

- 参照インタプリタは自分の `Heap`（10-08）を一つ持ち、組み込みの関数を呼ぶときだけ区間を開く（10-06「参照インタプリタ」）。変換は `runtime::heap` の公開の層の安全な関数（`ValueCtx`・`NoGcCtx`・`runtime::list`）だけを使う（ADR 0276 の帰結）。
- 自分の値からヒープの値へ: 即値は対応する `Value` の選択肢に、文字列・`Bytes`・構成子の値・リスト・`IOError` は対応する対象に変える。構成子の値は、引数がなければ `Value::Tag`、あれば `FieldsKind::Ctor` の値の並びにする。
- ヒープの値から自分の値へ: `ValueCtx::kind`・`fields_header`・`str` などで読み、同じ種類の自分の値に戻す。
- 組み込みの関数が引数や結果として関数の値・セル・`Host` の対象を受け渡すことは、第 1 段の範囲ではない（`Lazy.force`・`Reference.update` は `raw` を呼ばない。タスクの起動は `RefOutcome::Unsupported`。10-06「参照インタプリタ」）。変換できない種類に出会ったら `Stop::Internal` を返す。中身を見せない値（`Regex.Pattern` など。U3）は、ヒープの対象を参照インタプリタの側の `Slot` の表に保ち、自分の値はその表の位置を持つ形で後から加えられる。本作業ではこの形を `//!` に書き、中身は U3 か F14 が加える。
- 変換は、深いリストや深い構造でも Rust の再帰を使わない。
- 変換の後、区間を閉じる前に、結果を自分の値に戻し終える。ヒープの値を区間の外へ持ち出すことは型が禁じる（H3）。参照インタプリタのヒープの回収をいつ行うか（組み込みの関数の呼び出しのたびに `Heap::collect` を空の根で呼ぶなど）を決めて `//!` に書く。

### 組み込みの関数を呼ぶ手順

- 組み込みの関数の番号から `builtins::builtin_decl` で `BuiltinDecl` を引き、R07 の呼び出しの補助で `raw` を呼ぶ。応答の扱いは、第 1 段の VM と同じく 10-11「登録と第 1 段の扱い」の第 1 段の列とする（作業用のスレッドの仕事はその場で実行して完了の処理で結果を作る。`SpawnTasks` は呼び出し側が `Unsupported` にできるよう区別して返す。`Exit` は終了状態を返す）。
- 手順の結果の型は、F14 が評価で使える形（完了した値、止まる理由、終了、実行しない関数）にする。`pub(crate)` か `refinterp` の中に閉じた可視性にする。

本作業は差分テストを書かない。差分テストは、F14 と F18 が揃った後に C05（書き直したテストの差分）と C14（無作為のプログラム）が行う（10-06「作業の割り当て」、[ADR 0278](../../design/decisions/0278-stage-1-completes-on-new-syntax-tests.md)）。

## 受け入れテスト

- 往復: 種類ごとに、自分の値をヒープの値に変えて戻すと、元の値と等しい（自分の値の `=` で確かめる）。空の文字列、多バイトの文字、長さ 0 と 1 のリスト、引数のない構成子と引数のある構成子、入れ子の構成子、`IOError` を含める。
- 深い構造: 長さ 100 万のリストと、深さ 100 万の入れ子の構成子を往復させ、捨てても、スタックを使い果たさない。
- 変換できない種類: 関数の値を組み込みの関数の引数として変換しようとすると `Stop::Internal`。
- 組み込みの関数の呼び出し: R07 の見本（`Sample.absolute`・`Sample.repeat`・`Sample.readText`）を、自分の値の引数で呼び、結果が本体を直接呼んだ結果と一致する。溢れと上限の超えが同じ止まる理由になる。待つ見本がその場で完了する。テストの `IoServices` は、テストのモジュールに小さな実装を書く。
- 独立性: 値の型の定義が `runtime::heap` の型を欄に含まない（これはテストでなく、確認の観点で読む）。

## 完了条件

- `scripts/check.sh` が通る
- 受け入れテストのすべての場合を確かめるテストがある
- 値の型が `refinterp` の外に公開されていない
- 値の解放・等しさ・変換に Rust の再帰を使っていない

## 確認の観点

[実装の確認の観点](../00-common/00-04-review-checklist.md)の「参照インタプリタ（R10・F14）」に加えて、次の点を読む。

- VM の値の型や `runtime::equal` を、参照インタプリタの評価の側で使っていないか（変換の中だけで使っているか）。
- 変換が `runtime::heap` の公開の層だけを使っているか。
- 参照インタプリタのヒープが実行ごとに作られ、ほかの実行やテストと共有されていないか。

## 難易度の理由

値の型と変換は定型だが、VM と共有しない形を保ちながら、組み込みの関数の本体だけを共有する境目を作る。区間の寿命のため、変換は一回の区間の中で往復を終える形に限られ、F14 が評価を書きやすい形に整える判断が要る。
