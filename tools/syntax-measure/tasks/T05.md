# T05: A type class with implementations and constraints

Write a script that declares a type class (trait) `Priced` with one method that returns the price of a value in cents as an integer.

Declare two record types, `Product` (a name and a unit price) and `Subscription` (a name, a monthly price and a number of months), and implement `Priced` for both. The price of a subscription is the monthly price times the number of months.

Write a generic function that takes a list of values of any type `T` and one value `excluded` of the same type, and returns the total price of all elements that are not equal to `excluded`. The type parameter must require both the `Priced` type class and the built-in `equality` constraint.

In `main`, call the generic function once with a list of products and once with a list of subscriptions, and print both totals.
