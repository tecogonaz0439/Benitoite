# T15: Files, processes and effects

Write a script that takes a directory path as its only command-line argument. It lists the directory, and for every file whose name ends with `.txt`, opens the file for reading line by line (as a resource that is closed automatically), reads only its first line, and remembers the file name and the first line.

Then it writes a summary file `summary.md` in the current directory with one line per text file, prints the number of files that were summarized, and prints the value of the environment variable `USER` if it is set.

Declare precisely the effects each function needs, and import the standard modules that provide them. `main` returns an error message when the directory cannot be read or the summary cannot be written.
