# T06: Error handling with Result

Write a script that reads a configuration file `app.conf`. Each non-empty line has the form `key=value`; lines that start with `#` are comments.

Write a function that parses the text into a map from keys to values, and returns an error message that names the line number if a line has no `=`. Then write a function that builds a record `Config` with a host (a string, required), a port (an integer from 1 to 65535, required) and a debug flag (`true` or `false`, optional, default `false`). Each step can fail and must return a descriptive error message; propagate errors to the caller with the language's syntax for returning an error early, rather than nesting pattern matches.

`main` prints the configuration, or returns the error message.
