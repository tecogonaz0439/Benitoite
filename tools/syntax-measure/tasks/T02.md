# T02: Group CSV rows

Write a script that reads the file `sales.csv`. Its first line is a header `region,product,quantity,unitPrice`, and each following line is one sale with an integer quantity and an integer unit price, for example `north,apple,3,120`.

For every region, compute the number of sales and the revenue (the sum of `quantity * unitPrice`). Keep the result for a region as a pair of the region name and its revenue, and build a list of these pairs. Print one line per region, sorted by region name, in the form `north: 5 sales, revenue 1830, average 366 (remainder 0)`, where the average is the revenue divided by the number of sales using integer division, and the remainder is what that integer division leaves over.

Lines with a quantity or price that is not an integer are skipped. If the file cannot be read or parsed, `main` returns an error message.
