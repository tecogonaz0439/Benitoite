# T13: Maps and sets

Write a script that reads all of standard input as text and splits it into words (separated by spaces and line breaks; ignore empty words, and compare words in lowercase).

Print:

- the number of distinct words, using a set
- the frequency of every word, using a map from words to counts, sorted by word
- the words that occur in both the first half and the second half of the input (split the list of words in the middle), using set intersection
- the three most frequent words with their counts

If standard input cannot be read, `main` returns an error message.
