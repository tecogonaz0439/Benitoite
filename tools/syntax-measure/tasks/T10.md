# T10: Tests

Write a script with two functions and tests for them.

- `isLeapYear(year)`: whether a year is a leap year in the Gregorian calendar (divisible by 4, except years divisible by 100 that are not divisible by 400)
- `fizzBuzz(n)`: `"Fizz"` for multiples of 3, `"Buzz"` for multiples of 5, `"FizzBuzz"` for multiples of both, and the number as a string otherwise

Write at least four tests with descriptive names, using the standard assertion functions: check several years (including 1900, 2000 and 2024), check the four kinds of `fizzBuzz` results, and check with a boolean assertion that no number from 1 to 30 gives an empty string. The file does not need a `main` function.
