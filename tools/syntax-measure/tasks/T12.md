# T12: A small HTTP server

Write a script that runs an HTTP server on `127.0.0.1`, port 8080, using the standard library's server function that takes a request handler.

The handler must answer:

- `GET /` with the text `welcome`
- `GET /hello/<name>` with the text `Hello, <name>!`
- `GET /add/<a>/<b>` with the sum of two integers as text, or status 400 with an error text if either part is not an integer
- `POST /echo` with the request body as text
- anything else with status 404 and the text `not found`

Route the requests by matching on the request method and the list of path segments. `main` returns an error message if the server fails to start.
