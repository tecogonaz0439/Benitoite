# T03: Classify events with pattern matching

Write a script that defines an algebraic data type for log events with these cases:

- a login, with the user name
- a logout, with the user name
- a purchase, with the user name and the amount in cents (an integer)
- an error, with an integer status code

Write a function that turns an event into a short description:

- logins and logouts are both described as `session event for <user>` (handle them in one pattern-matching arm)
- a purchase of more than 100000 cents is `large purchase by <user>`; other purchases are `purchase by <user>`
- an error with a code from 400 to 499 is `client error <code>`, from 500 to 599 is `server error <code>`, and any other code is `unknown error <code>`

Also write a function that returns whether an event is suspicious: a login by the user `admin`, or an error whose code equals 500. In `main`, build a list of at least six events, and print the description of each event, followed by `(suspicious)` when the event is suspicious.
