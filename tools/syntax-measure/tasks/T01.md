# T01: Sum a field in a JSON file

Write a script that reads the file `orders.json` in the current directory. The file contains a JSON array of objects such as:

```json
[{"id": 1, "customer": "Ann", "amount": 1200}, {"id": 2, "customer": "Bob", "amount": 300}]
```

The script prints the number of orders and the total of the `amount` fields, for example `3 orders, total 2700`. Objects whose `amount` is missing or is not an integer are skipped and counted separately; print that count too.

If the file cannot be read or is not valid JSON, `main` must return an error with a message that says what went wrong, instead of printing a total.
