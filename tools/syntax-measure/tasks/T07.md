# T07: Recursion over lists

Write a script with the following functions. Do not use any library function that processes the whole list for you (such as a map, filter or fold function); write each function with recursion and pattern matching on lists.

- `sumOfEvens(xs)`: the sum of the even numbers in a list of integers
- `runLengths(words)`: for a list of strings, a list of pairs of a string and a count, one pair for each run of equal adjacent strings. For `["a", "a", "b", "a"]` the result is `a` with 2, `b` with 1, and `a` with 1.
- `interleave(xs, ys)`: the elements of two lists taken alternately; when one list runs out, the rest of the other follows
- `lastElement(xs)`: the last element of a list, or nothing when the list is empty

In `main`, call each function on an example and print the results.
