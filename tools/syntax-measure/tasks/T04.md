# T04: Records and record update

Write a script that manages a small library. Declare a record `Book` with a title, an author, a year of publication and the number of available copies.

Write these functions:

- `lend(book)`: returns the book with one copy fewer, or an error message if no copy is available
- `giveBack(book)`: returns the book with one copy more
- `describe(book)`: returns a line such as `"Dune" by Frank Herbert (1965), 2 available`
- `oldest(books)`: returns the book with the smallest year, or nothing if the list is empty

Use the record-update syntax to change the number of copies. In `main`, create three books, lend one of them twice, give it back once, and print the descriptions of all books and the title of the oldest book.
