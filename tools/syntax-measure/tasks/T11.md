# T11: Concurrency

Write a script that receives file names as command-line arguments. It reads all the files concurrently, as separate tasks that run at the same time, and waits for all of them to finish.

For each file, print its name and its number of lines, or its name and the error message if it could not be read. Finally print the total number of lines of the files that could be read. If no file names were given, print a usage message and return an error from `main`.
