# T08: String processing and interpolation

Write a script that turns a list of titles into a small HTML page.

First write a function that normalizes a title in several steps: trim the surrounding spaces, convert it to lowercase, replace every space with `-`, and remove every `?` character. Write each step as a separate statement, and give the intermediate result the same variable name, `title`, in every step.

Then build the page as a multi-line string: an `<h1>` heading with a page name taken from a variable, followed by one `<li>` line per title that shows the original title and the normalized one, and a final line with the number of titles. Use string interpolation to insert the values. Print the page.
