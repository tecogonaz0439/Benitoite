# T09: A user-defined effect and handler

Write a script that declares an effect `Ask` with one operation that takes a question (a string) and returns an answer (a string), and a second operation that records a note (a string) and returns nothing.

Write a function `interview` that asks for a name and an age, records a note for each answer, and returns a greeting that includes both answers. The function must not know where the answers come from.

In `main`, run `interview` with a handler that answers the questions from a fixed map of questions to answers (with a default answer for unknown questions), prints each note to the console, and resumes the computation after each operation. Print the resulting greeting.
